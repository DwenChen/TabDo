# TabDo

<img src="resources/icons/icon.png" width="96" alt="TabDo 浅绿色鼠标图标" />

**把常用操作带到鼠标旁。**

TabDo 是面向 Windows 的桌面工具箱。选中文字、图片、文件或窗口，呼出超级面板，即可选择适合当前内容的操作；在空白处呼出，则可打开固定的常用工具。

项目由 DwenChen 独立维护，源自 ZTools，保留原项目与插件作者的署名和许可。当前功能说明以 **1.5.5** 为基准，逐版变化见 [更新说明](changelog.md)。

## 下载与安装

目前提供 **Windows 10 / 11 x64** 版本。录屏要求 Windows 10 1903 或更高版本，部分原生捕获效果取决于系统和设备。

| 文件                             | 使用方式                                                 |
| -------------------------------- | -------------------------------------------------------- |
| `TabDo-<版本>-win-x64-setup.exe` | 安装后使用                                               |
| `TabDo-<版本>-win-x64.zip`       | 完整解压到独立目录，再运行 `TabDo.exe`；保留所有配套资源 |

从 [Releases](https://github.com/DwenChen/TabDo/releases/latest) 下载。更新前退出程序并保留原数据目录；使用旧 fork 仓库版本时，先阅读 [升级说明](docs/release.md#从旧仓库版本迁移)。

免安装 ZIP 表示程序无需安装，不表示用户数据默认保存在程序目录。数据默认位于用户主目录下的 `.tabdo`。仓库内的手动测试另有隔离启动器，见 [开发指南](docs/development.md#本地免安装交付)。

## 快速开始

1. 启动 TabDo，左键点击托盘图标打开设置。
2. 在“通用设置 → 超级面板”选择鼠标触发方式和长按时间。
3. 呼出面板，试用首次固定的“截图、剪贴板、便签、文件搜索、录屏、演示录屏、呼叫AI”；再尝试选中文字或文件后呼出。
4. 按需在“快捷键”启用按键，在“提供商”配置识别与翻译，在“插件市场”安装扩展。
5. 打开“设置 → 关于 → 阅读本地教程”，查看完整操作步骤。教程随应用提供，断网可读，首次启动不会自动弹出。

全新配置的应用级快捷键和“设置”来源指令默认关闭，已有选择继续保留。录屏通过独立控制条停止；F10 需先启用。Windows 11 新配置默认使用云母材质，其他系统默认无材质，不覆盖已有设置。

## 超级面板

选中文字、图片、文件或窗口后，用鼠标中键、侧键或长按呼出面板，直接执行适用操作；空白处呼出显示自己固定的工具。常用入口可排序、分组，也可设置别名和快捷键。开启选文自动翻译后，译文直接出现在面板中，以中文为主的文本默认跳过。

## 演示录屏

**从录制到带运镜的成片，在一个工具里完成。** 适合软件教程、产品演示和操作说明，常见剪辑无需再打开单独的剪辑软件。

- **自动运镜与变焦**：根据录制时的点击、移动和停留聚焦操作区域，平滑放大细节并回到全景。“变焦”支持 1–5× 连续倍率、2D/3D 镜头切换；3D 镜头可拖动调整角度、选择预设，并设置焦距、光圈、景深、对焦点和屏幕反光。镜头从完整录屏平面取景，放大局部不再因卡片旋转额外露底，看到真实录屏边缘时才显示原背景。新增片段默认 2D、1.5×；预览与导出使用相同镜头，切换模式保留参数。变焦片段可分别设置 0.25–4× 的视频倍速和镜头动画倍速。通用设置提供默认开启的连接变焦与“平滑 / 专注”运动效果。
- **录完直接编辑**：时间轴支持裁切、分割、变速和标注；可调整光标动画、点击效果、背景与录屏的独立圆角和阴影；紧凑裁剪支持移动、八向缩放、重新框选和常用比例。高级选项在侧栏下部展开，重置位于右上角并恢复当前分类的出厂选项。新项目使用默认外观，已有项目恢复各自设置。
- **独立轨道与标注**：演示录屏始终录制鼠标；按需开启“录制按键”、系统音频、麦克风和摄像头。停止后按键自动载入轨道，在“按键”侧栏通过“显示按键输入”开关控制显示，并在下方调整外观；关闭显示保留已编辑内容，右上角“重置”恢复默认外观和显示。系统音频、麦克风和摄像头素材自动进入独立轨道，名称固定在左侧；点击声音调整音量、响度及淡入淡出滑条，素材起点随片段裁切和分割自动确定；摄像头画中画仍在侧栏设置。先选中片段定位到起点，再用时间尺设置切点；剪刀只分割该片段；切口紧邻且无竖条。各类片段右键菜单均提供“复制”“粘贴”和“删除片段”，也可在游标处分割；声音另可静音或恢复音量。复制保留素材偏移和外观，粘贴到游标处；单轨空间不足时寻找后方完整空隙，多轨自动避开重叠。拖动片段可调整同轨顺序，拖动左侧轨道名称可调整整轨排列，顺序随项目保存。拖动时显示落点提示，名称旁不显示手柄。缩放与横向浏览及时更新视频帧图，所有类型片段选中后显示明显轮廓，变焦、注释和声音同时常显两端长度手柄；点击固定刻度或片段外留白可定位游标。音频悬停显示名称、起止时间和时长。底部比例滑杆与加减按钮调整展示尺度，“适应全部”恢复全览；滚轮上下浏览，Shift＋滚轮或横向滚动条左右浏览，Ctrl＋滚轮调整比例。编辑片段时保留已选比例，刻度与显示到毫秒的游标时间在纵向滚动时固定。注释可拖动方框上方的圆形手柄旋转，按住Shift以15°对齐，也可在侧栏调整角度；箭头方向由旋转控制。所有类型片段选中后暂停定位到起点；移动注释后预览定位到片段内，移动、旋转及片段粘贴删除均支持撤销和重做。摄像头素材在侧栏替换，删除区间使用片段右键菜单。注释的模糊和马赛克相邻，图片及聚焦、模糊、马赛克的矩形遮罩提供圆角调节；圆形和手绘遮罩隐藏圆角控件，切回矩形保留原值。
- **时间轴关联**：录屏重排只移动实际覆盖画面的变焦和注释，分离部分拆段；字幕按源时间投影，独立声音及摄像头保留各自时间位置。新增注释自动分配空闲导轨、滚入视口，图标随类型变化。详见[时间轴关联规则](docs/presentation-timeline.md)。
- **声音与人像**：录制屏幕或应用窗口，可按需加入系统声音、麦克风与摄像头画中画，编辑时可直接在预览中拖放人像，通过宽高滑条和比例锁定调整大小；人像默认最大圆角，圆角与阴影位于普通设置。录制到的系统音频和麦克风首次加载即为独立音轨，点击可分别设置。
- **继续编辑或直接分享**：项目和改动自动保存，支持 .recordly 项目导入、已有视频导入，以及视频和 GIF 导出。项目引用的素材需一并保留；普通视频没有操作轨迹时可手动添加缩放。
- **预览与视觉效果**：预览音量旁可进入全屏，并可拖动底部进度条定位，编辑鼠标始终可见。按键以带阴影和高光的实体键帽呈现，空格、回车及方向键使用键盘符号，通过单一“键帽大小”控件统一缩放，并可调整按键分组最大间隔。模糊、马赛克及聚焦支持矩形、圆形和手绘遮罩；箭头提供六款白底黑边的可换色卡通 SVG 外观，默认更小；所有注释及按键的动画默认关闭，启用后可调时长。详见[预览、按键与注释](docs/presentation-visual-effects.md)。

“演示录屏”直接打开浮动控制条，停止后进入编辑器；控制条的“演示编辑器”可管理项目。编辑器最小化或失焦时保留当前页面。只想快速保存画面时，使用独立的“录屏”，支持全屏、窗口、区域、倒计时和操作效果。

## 剪贴板

自动保存复制过的文字、图片与文件记录，按类型或关键词查找，支持收藏、备注、多选、复制并粘贴和拖出。关闭页面后继续采集，历史保留天数可调整；文件条目引用原文件。

## 悬浮中转

把当前任务需要的文字、图片和文件收集到一个小窗口。打开后自动追加新复制内容，可多选、调整顺序、预览图片，再复制或拖到其他应用。文本、图片和文件分别取用；关闭后清空本次中转，剪贴板历史、收藏与原文件保留。

从剪贴板条目或右侧中转按钮进入，空入口可打开一个空收集篮，适合跨应用整理多段资料。

## 便签

独立纸张窗口用于临时记事，隐藏任务栏图标，支持多张便签、撤销与重做、配色、透明度和字号调整。拖到屏幕边缘可收成色签，点击再展开。便签正文仅属于当前窗口，关闭前请把需要留存的文字复制到自己的文档。

剪贴板图片还可“悬浮固定”为参考图，或进入“图片标记”编辑。图片标记与截图共用九项标记工具，包括箭头、荧光笔、文字、马赛克、单击递增的序号圆圈，以及拖选区域的聚光灯；标记可撤销、重做，并随图片复制或保存。

## 其他内置工具

**呼叫AI**提供一次性 Agent 对话，复用“提供商”模型，内置 Node.js 和 Python。支持请求批准与完全权限，输入“/”手动引用 Skill 或 MCP。设置侧栏的“呼叫AI”管理 Skill ZIP、MCP、全局规则和默认产物目录。对话支持拖入或粘贴文件、图片与文件夹，可一次审批批量创建文本文件。点击回复中的产物链接可打开文件，旁边的图标可在文件夹中定位。聊天窗的“网页搜索”默认关闭，开启后可抓取和检索网页，直连 DeepSeek 时使用官方接口，其他提供商可配置 Brave Search 或博查搜索。聊天在独立窗口中打开，最小化或失焦时保留会话。关闭后释放聊天、进程与临时文件，保留结果文件。聊天支持公式、代码高亮与复制，AI 可在同一条回复中穿插静态 HTML、架构图、流程图和原理图，并导出 SVG。详见[呼叫AI说明](docs/call-ai.md)。

| 分类           | 功能                                                            |
| -------------- | --------------------------------------------------------------- |
| 截图与取色     | 屏幕截图、屏幕取色                                              |
| 文字与公式识别 | 图片文字识别、行框与局部选文、译文、LaTeX 预览及复制            |
| 文件搜索       | 通过 Everything 搜索，支持分类、预览、右键操作、拖出和多选复制        |
| 文件整理       | 批量重命名、解散文件夹、复制路径或名称、打开目录和终端          |
| 图片处理       | 压缩、格式转换、尺寸、裁剪、水印、旋转，以及图片、PDF、GIF 合并 |
| 视频处理       | 压缩、截取、裁剪、格式转换、倍速、水印、合并、音频和帧提取      |
| 网页与系统     | 网页快开、网页搜索、以图搜图、窗口信息及系统操作                |

普通入口采用唯一中文名称；匹配入口按输入类型出现。完整功能码、分类和图标见 [工具清单](docs/tools-catalog.md)。

离线识别和翻译需要先下载资源，离线翻译目前支持英译中。在线能力需要网络及对应服务配置；OCR 行框取决于提供商是否返回坐标。便签内容属于当前窗口，关闭后结束。格式、设备及资源限制见 [识别与翻译](docs/builtin-providers.md)、[媒体工具](docs/media-tools.md)。

图片和视频按队列批量处理，可先查看预览、框选裁剪范围或选择视频片段，再统一输出新文件，源文件保留。默认输出到各源文件同级目录，合并取首项所在目录，也可选择自己的输出位置。

## 插件扩展

[TabDo-plugins](https://github.com/DwenChen/TabDo-plugins) 独立管理插件源码、索引、图标和发布包。应用支持从市场或本地 `.zpx` 文件安装。

插件采用 `session-v1` 生命周期：默认退出即释放页面、模型与工作进程，必要任务按时限完成并清理。旧市场插件需适配并验证后收录。开发入口见 [插件规范](docs/plugin-development.md)、[提供商指南](docs/provider-development-guide.md)和[市场规范](docs/plugin-market.md)。

## 按需运行与临时常驻

工具和插件退出后释放临时资源；保存、文件事务或编码等必要任务完成后收尾。配置、收藏、历史和已安装插件继续保留。

支持的页面在宿主标题栏右上角提供“临时常驻”：开启后将当前会话保留在独立窗口，隐藏或最小化仍可继续；取消开关会立即关闭该会话。状态默认关闭、不跨重启保存。它与图钉“置顶”分别控制会话保留和窗口层级。

## 数据与网络

默认数据目录为用户主目录下的 `.tabdo`，可在设置中调整。配置、剪贴板历史、收藏及插件资料在本机保存；选择在线翻译、AI、网页或图片搜索时，相应输入会发送给所选服务。

完整备份包含插件私有资料、服务密钥及会话，当前格式不加密，应保存在可信位置。目录迁移在退出后逐文件校验，保留原件。范围、恢复与回滚见 [数据备份与迁移](docs/backup-and-migration.md)。

## 开发与贡献

技术栈为 Electron、Vue 3 和 TypeScript，使用 Node.js 22、pnpm 9.15.9。准备环境后，可直接从源码预览：

```powershell
git clone https://github.com/DwenChen/TabDo.git
cd TabDo
pnpm install --frozen-lockfile --ignore-scripts
pnpm --dir internal-plugins/setting install --ignore-workspace --frozen-lockfile --ignore-scripts
node node_modules/electron/install.js
node node_modules/ffmpeg-static/install.js
pnpm hooks:install
pnpm preview:local
```

上述安装方式跳过依赖脚本，再分别安装 Electron 与 FFmpeg 预编译运行文件。源码预览和 Electron E2E 使用隔离数据，无需先打包。环境排查、模块入口、测试与交付命令见 [开发指南](docs/development.md)。
