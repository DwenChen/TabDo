# 悬浮窗口界面来源

界面复用 [ZToolsCenter/ZTools-plugins](https://github.com/ZToolsCenter/ZTools-plugins/tree/c8475ad7944ffdb78843cc5f56886d1443d0a724) 的 MIT 授权实现，版本固定为 `c8475ad7944ffdb78843cc5f56886d1443d0a724`；完整许可在同目录 `LICENSE.floating-ui`。

- `tools-floating-base.css` 为 `plugins/clipboard-image-paintbrush/floater.css` 的原样副本。
- `tools-floating.html` 复用 `plugins/clipboard-image-paintbrush/floater.html` 的窗口结构、拖动区域与缩放手柄；本地重做标记栏，采用截图的白底、深灰细线图标与浅蓝选中态，保留颜色圆圈弹出色板、五档笔触大小点及受限宿主 IPC。九项标记的顺序、名称和 SVG 来自 `annotation-tools.js`，原生截图编译时使用同一图标源；荧光笔、箭头、序号圆圈和聚光灯图标按该风格绘制。
- 便签复用 `plugins/sticky-note/dist/assets/float-Dp0v4fhg.css` 中的窄彩色标题栏、正文与五组纸色，并增加透明纸张折角。只使用界面部分，编辑内容属于当前窗口，关闭后释放，不载入上游编辑器及持久化历史代码。

宿主使用透明无系统边框窗口，标注历史保留在内存矢量列表。导出图片不包含窗口工具栏或便签外观。

序号圆圈单击放置，序号随有效历史推进，撤销与清空后重新计算；聚光灯以多个矩形区域的并集保留亮度，其余区域统一压暗。两类标记参与撤销、重做、复制和保存。聚光灯绘制使用局部裁剪，不长期缓存整张遮罩。橡皮擦保留在图片操作组，便签及普通悬浮图片的界面不受标记栏重做影响。

便签初始 300×280，首张柠檬黄，主动新建按五种纸色轮换；最小 220×140，并支持四边和角落缩放。置顶使用独立图钉按钮。图片窗口按原图与当前工作区适配，工具栏高度以实际换行为准；每个标记工具分别保留当前窗口的颜色和笔触，荧光笔默认荧光黄；文字还独立保留字号。

图片悬浮使用无标注工具栏模式，置顶和关闭按钮保持半透明淡显，系统鼠标进入图片后完整显示，复制/保存快捷键仍可用。便签编号与轮色只属于当前存活窗口组，全部关闭后重置为黄色「便签 1」。接近工作区四边约 20 DIP 或拖过边缘时均可贴靠，释放后立即收起为同色编号标签，拖动中暂停不收起，悬停不展开；点击或把标签拖离边缘解除贴靠，标签可以沿边缘自由移动，并同步纸张恢复位置。收起通过缩小可见窗口实现，不能使用 hide 触发便签销毁。

便签标题栏和普通悬浮图片使用客户区指针捕获拖动；标记工具栏仍保留原生拖动区。宿主每 80ms 读取一次系统鼠标与窗口坐标，拖动期间不判定贴靠，释放时立即判定；稳定位置观察与图片按钮悬停继续共用此观察器，避免依赖原生 app-region 的页面悬停。观察器由所有独立可见窗口共享，最后窗口关闭即停止，标记窗口不参与。纸张最小尺寸由受限缩放入口维持；宿主保存正常纸张尺寸，避免切换最小尺寸或多次移动时累积 Windows DPI 舍入误差。

图片标记工具栏左侧使用图片图标与“图片标记”标题标识窗口，替代无操作含义的三颗装饰点；该区域仍可拖动窗口。标题保持单行，窄窗口允许收缩，避免挤压缩放和保存等操作；供应商基础样式保留原样，本地调整放在 `tools-floating.css`。

贴靠过渡为 200ms 缓出，拖出色签时立即接续纸张拖动；竖排标签去掉空格与字距并使用 upright。贴靠开关同步控制本次运行全部便签，字号只影响当前便签。普通悬浮图片的画布通过百分比铺满窗口，关闭滚动条，避免连续缩小时旧画布造成透明区域；移动固定最近缩放的逻辑尺寸，避免 Windows 非整数 DPI 下反复读回边界导致尺寸涨大。

图片箭头沿用截图的渐宽箭身与内凹机翼头，箭尾按用户要求收成单一尖点，消除平切端面。马赛克使用与截图一致的原图采样/蒙版并集：马赛克笔、框选马赛克两种模式，三档浓度统一作用于已有区域，笔刷大小独立选择，连续路径没有落点空隙。圆圈准星和框选边界仅为DOM预览，不进入复制或保存。低分辨率采样仅在当前有效马赛克存在时保留，浓度切换、清空和退出释放。文字框改为透明底及对应颜色边框，随输入伸展并按原图落点及缩放定位，配色期间保留焦点与正文。

马赛克二级工具按截图的DrawMosaicPopup改成纯图标：波折涂抹轨迹、矩形、三种棋盘格和大小圆点；移除“浓度”文字及下拉框，以title/aria-label解释含义。参数区左侧浅灰竖线与主工具分隔，内部细竖线区分模式、浓度和半径，默认与窄窗口均保持完整显示。

所有标记工具的二级选项各自记忆，切换后恢复自己的颜色、笔触和文字字号，马赛克保留自己的模式、浓度与半径。文字工具以三枚不同大小的A图标选择16/24/36像素，不再使用笔触圆点；输入中改字号仍保留焦点及正文，并同步缩放后的输入框和最终图片。普通工具的二级配色区同样以浅灰竖线与主标记分隔。
