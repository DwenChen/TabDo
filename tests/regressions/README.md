# 历史故障回归集

收录 TabDo 工具、截图、剪贴板、鼠标触发、插件宿主及免安装预览的历史故障，并组织相邻功能的兼容性检查。自动化测试、人工验收和待补自动化分别标记；列入清单不代表本次已执行或全部通过。

## 运行入口

`documentation` 覆盖文档发布门禁：有效/失效链接和锚点、工具清单统计与功能身份、教程正文漂移、插图缺失及真实教程页面。`pnpm docs:check` 是每次 push、云端构建、Release 的必经校验，不能替代人工行为、操作名与语言审校。

`media-note-interaction` 覆盖 TX-68/69/70：两轮26文件混合正常、损坏和注入原生崩溃，逐行完整返回；尺寸预选、比例框选、真实裁剪输出、快速切换取消预算、视频播放时间设起止点和临时资源清理；真实系统鼠标拖动便签进入相邻组，检查自然编号排序、错位、文字范围不与其他色签相交、点击展开保留正文。`media-tools` 和 `floating-pointer` 同步收录相关新单测。源码 E2E 不打包，两个资料根都隔离。原始报错图片未提供，特殊解码器、声音、其他屏幕/DPI 与最终观感保留人工验收。

`performance` 覆盖对应历史改动性能回归：TX-62（Session preload/代理幂等、切换关闭身份、RPC 超时清理、索引不生成深层代理），TX-63（首帧与复制并行、请求过期、隐藏清空与真实 30 秒闲置回收、网页文本菜单直达），TX-64（剪贴板/图标缓存及文件 I/O 预算、媒体最新请求取消收束）。性能数字仅作为同机源码对照，详见 [性能审查](../../docs/performance-audit.md)。

- TX-62：`pluginRuntimeResources`、`proxySessionReuse`、`commandSearchResources` 和宿主源码回归核对 Session 注册、通信收束、视图切换与索引更新。
- TX-63：`performance-budget` 对照首帧、二级菜单与闲置释放；`super-panel-selection` 保留真实 Windows 选区、文件及取消链。
- TX-64：`asyncPool`、`iconProtocol`、历史分类压力检查和 `media-batch` 快速换图核对并发、缓存与过期取消；`settingsSubInputResources` 验证 20 次设置页面生命周期及失败重试计时器回收。

对应历史改动新增 `tools-expanded` 回归组：TX-01（规则工作流、交换改名、冲突/变化检测、取消与失败回滚）；TX-02（二维码真实解码与 HTTP(S) 点击）；TX-03（图片文件分类及原文件载荷）；TX-04（无边框窄窗口、原插件工具栏、独立色板和五档笔触、标注复制与窗口释放）；TX-05（文字条目快捷悬浮、纸张配色与折角、关闭不持久化、匹配文本优先、多窗口追加路由及独立/快捷新建）；TX-06（Everything 中文 IPC、分页/参数及查询进程释放）；TX-07（完整译文滚动）；TX-08（进入、换图与切换模式后自动识别，由 `builtin-providers` 覆盖）。新增 `tools-polish` 专项组：TX-09（黄色小便签、轮换新窗口颜色、独立置顶和边缘缩放）；TX-10（图片贴合、文字焦点、荧光笔颜色隔离、五档笔触）；TX-11（原搜索布局、连接指引与分类预览）；TX-12（自动翻译关闭与语言设置、双栏识别及 LaTeX 预览）。该组仅运行相关两个源码 E2E 文件和提供商单测，不运行全量回归。跨应用选区、多屏/DPI 与视觉手感保留人工验收。

`settings-defaults` 专项覆盖快捷键集中归类与默认全关、开发者折叠、黑名单和调试日志完整删除、托盘菜单与游戏模式、设置指令默认禁用和五个默认固定工具、目录迁移的失败边界及真实退出重启资料保留（TX-53～55）。相邻宿主、录屏和退出流程纳入同组。

`clipboard-trigger` 是复制后匹配的专项单测组（TX-57）：通过登记给原生监视器的回调进入宿主触发链，覆盖七种按键配置、切换、选区优先、过期/0 秒、图片文件、屏蔽和取消；同组运行剪贴板时效和免打扰既有测试。UI 控件按 TX-56 视觉验收，对应历史改动未运行 E2E。

清单来源为 [suites.json](suites.json)。分组允许组合，共用测试文件自动去重。以下命令在项目根目录执行：

```powershell
# 只查看后续要执行的测试，不启动服务或 Electron
pnpm test:regressions --list

# 按本次修改的范围选择分组
pnpm test:regressions clipboard
pnpm test:regressions panel --e2e
pnpm test:regressions host --e2e
pnpm test:regressions screenshot --e2e
pnpm test:regressions clipboard panel --unit
pnpm test:regressions preview --unit
pnpm test:regressions clipboard-trigger --unit

# 已同步的免安装预览：只读比较当前编译产物与预览资源，不构建、不启动应用
pnpm test:preview:resources

# 需要完整复查历史故障时才执行；并非项目所有测试
pnpm test:regressions
```

日常修复优先选择相关分组，不默认运行整个历史集或项目全量回归。`--unit` 只运行单测，`--e2e` 只运行 E2E；同时传两者等同于均运行。

E2E 继续使用 `playwright.e2e.config.ts`，等价于通过 `pnpm test:e2e <文件>` 筛选已有测试。由 `scripts/preview-local.cjs --servers-only` 自动准备源码服务，使用 `scripts/preview-main.cjs` 启动隔离 Electron。不得为 E2E 打包、生成 out/dist、使用免安装成品或下载另一份 Chromium。每个实例同时隔离 `TABDO_DATA_ROOT` 与 `TABDO_LEGACY_USER_DATA_PATH`，不读写真实配置和插件。Windows 原生输入及截图用例需要可交互的 Windows 桌面，会移动鼠标并操作测试窗口；非 Windows 跳过不视为通过。

`builtin-models.spec.ts` 需显式 `TABDO_MODEL_TEST_ASSETS` 指向私有归档，以真实资源验证安装、OCR、公式推理和删除。常规跳过不计为通过。该测试记录公式期望与实际输出；当前系统字体公式样例出现误识别，仍需人工核对精度。真实在线翻译账号额度、Google/Microsoft 网络可达性和实际用户模型质量尚未通过外部服务验收。

这些场景也属于后续回归集，执行时应逐项记录结果，不能用上一节通过数替代。截图工具栏是原生窗口，无 DOM；当前 E2E 会输出工具栏和长截图供检查，但没有对翻译图标、间距或拼接像素连续性作自动断言。
