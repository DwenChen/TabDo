# 演示预览、按键与注释

预览音量旁的“全屏预览”复用当前播放器，保留媒体时间、画幅和图层。普通及全屏预览底部均提供进度条，支持拖动或键盘定位，并显示当前位置与总时长；定位会暂停播放，按编辑后的时间轴映射到对应素材。全屏底部可播放、暂停、跳转及调节音量，点击音量旁的退出全屏按钮或按 Esc 返回。嵌套页面无法进入浏览器全屏时，自动改用所属编辑器窗口的原生全屏；退出、换项目或关闭会恢复本次预览接管的窗口状态。失败提示仅显示在预览内，可关闭并在六秒后自动消失，不触发素材恢复或阻止其他项目打开。全屏不写入项目或改动布局偏好。编辑用系统鼠标始终可见，与作品里录制的光标独立。

## 按键录制与键帽

控制条“录制按键”默认关闭，关闭时图标带左上至右下的斜线，与其他关闭状态统一，开启后采集物理按键和组合键。空格保存为显式 Space；旧项目的空白空格同样显示为 ␣，回车、删除、Tab、方向键等使用键盘图例。记录不包含输入法提交文本。

“按键”侧栏提供五种实体键帽外观，包括键壁、高光及投影。设置按外观、大小与配色、按键分组、当前片段内容和动画组织。“键帽大小”是唯一大小控件，范围25%–300%，同步缩放文字、键帽及显示框并尽量保持组中心；切换外观不改变当前大小。不再分别提供字号、显示区域宽高或框角缩放，在预览中仍可拖动位置和旋转。旧项目的字号与键帽倍率折算显示，调整前不改写。绘制为阴影留白，长组合超出可用画面时整体缩小。文字颜色与底色复用注释颜色菜单，可选预设、调整颜色或输入十六进制色值。

“连接相邻输入”默认开启，其下“按键分组最大间隔”默认800ms，可调100–3000ms。间隔以前后两次按键按下的时间差计算；小于或等于设定值时，依次呈现为同一组键帽，超过则另起一组。关闭连接后每个事件独立显示。连接时依次呈现已输入的键帽，整组共享进出场，最多连接最近12个事件、呈现32个键帽。原始片段、内容、位置和时间不被改写；同轨重叠时取最新事件，不以多个整框相互覆盖。不同轨道仍允许独立叠加。旧项目已经保存的累积文本按原内容读取。

“变焦 → 通用设置”开启“连接变焦”后显示“变焦衔接最大间隔”，范围0–5000ms，缺省1500ms。相邻两段变焦之间的空白时长小于或等于设定值时，保持放大状态并衔接下一段；超过则分别进出场。重叠或首尾相接按零间隔计算，关闭连接时隐藏滑条但保留参数。二维、三维镜头、预览与导出共用该阈值。

单独按下左右 Shift、Ctrl、Alt、Meta 时立即记录，组合键同时保留修饰键和主键。修饰键长按不重复生成事件，左右键分别追踪松开；暂停或关闭采集不新增输入，结束订阅时释放临时按下状态。连接输入只折叠紧邻组合键前的重复修饰键图例，不删除原始事件。小键盘关闭 NumLock 后的方向、导航和删除键也使用对应图例。

## 形状与手绘遮罩

模糊、马赛克和聚焦共用矩形、圆形与手绘涂抹。圆形随显示框宽高形成圆或椭圆；矩形保留原圆角。切换形状保留笔画和圆角，支持以后切回。

选择手绘后，在预览中选中注释并点击“涂抹遮罩”，按住鼠标绘制；“完成涂抹”恢复对象拖动，Esc 取消当前笔画。笔刷以较短边百分比计，支持4–60%，默认16%；每一笔只占一个撤销步骤，侧栏“清空笔画”可清空当前对象的涂抹范围。空笔画时不应用局部效果；聚焦的空笔画意味着没有透明孔，外围遮罩覆盖全画面。笔画相对对象保存，移动、旋转和缩放后继续跟随。

## 箭头与动画

箭头外观通过缩略图选择，共六种：直线、饱满、双向、虚线、弧形和缎带。统一采用可换色 SVG、深色卡通描边及柔和投影，支持颜色、线宽、八方向、旋转和等比缩放。新箭头默认白色弧形，初始显示框为画面16%宽、8%高。预览、缩略图及各导出链共用矢量材质；旧颜色与尺寸保留，晶透、霓虹和叠影标识分别归并为饱满、直线和双向外观。

“光标”保留 macOS、金门、反色金门、Windows 11、圆点和极简六种内置外观。已移除蓝晶、果冻、珍珠及折纸；原项目选择这些外观时使用标准光标，其他自定义外观标识保留。

文字、图片、箭头、模糊、马赛克、聚焦和按键均提供进入与退出效果：无、淡入淡出、弹性缩放、浮入浮出、擦除；动画时长可调80–1500ms，默认280ms。短片段自动把每段动画限制到时长一半，避免进出场重叠。普通注释与按键的缺省进入、退出效果均为“无”。仅在任一效果非“无”时显示动画时长；隐藏时保留已设时长，旧项目显式选择的动画继续读取。以媒体时间计算，暂停和拖动时间尺可查看具体帧。

参数保存在片段样式中，沿现有自动保存、复制、分割、撤销和重做链工作；旧项目缺失形状时使用矩形。预览、标准和现代导出共用键帽绘制、遮罩几何与动画时间函数，现代导出在存在注释时逐帧合成。资源仅服务当前预览或导出实例，退出时释放所属画布。

侧栏遵守[统一UI规范](presentation-inspector-ui.md)，轨道时序遵守[关联规则](presentation-timeline.md)，重置边界见[默认值](presentation-editor-defaults.md)。验证入口为 `presentation-visual-effects` 回归分组；多屏、其他DPI、触控与主观动画手感仍需人工验收。
