# 演示编辑侧栏 UI 规范

原缩放检查器现名“变焦”，2D/3D镜头模式与自动/手动取景分别呈现；连续倍率、镜头角度和光学参数沿共享SliderControl展示，不另设字号、主题或折叠变体。具体操作与数据边界见[变焦镜头](presentation-zoom-camera.md)。

本规范适用于场景、光标、按键、摄像头、变焦、音频、字幕和注释检查器。新增或修改这些界面时必须遵守，不能为单个页面另建字号、灰色标题或滚动条。通用工具约束见 [工具开发规范](tools-development.md)，验证与交付见 [维护流程](maintenance.md)。

按键尺寸、相邻输入连接间隔、遮罩形状和通用动画控件沿用共享行、滑条与文字层级。箭头外观以缩略图选择，中文名称放入无障碍名称和悬停说明。操作与数据规则见[预览、按键与注释](presentation-visual-effects.md)。

按键按外观、大小与配色、分组、当前片段内容和动画组织。“键帽大小”统一缩放文字、键帽与显示框，不另外暴露字号或框宽高；颜色沿用注释的完整颜色菜单与预设色板。连接间隔必须标明“最大间隔”并解释计时起点及小于或等于阈值时的行为；动画时长仅在至少一个进出场效果启用时出现。

## 文字层级

| 层级 | 字号 / 行高 | 字重 | 颜色 |
| --- | --- | --- | --- |
| 编辑菜单标题 | 14px / 22px | 500 | 主题正文色 |
| 设置小节、折叠标题 | 13px / 21px | 500 | 主题正文色 |
| 子选项、标签、数值、普通选项文字 | 12px / 20px | 400–500 | 主题正文色 |
| 描述、单位解释、当前素材文件信息 | 11px / 18px | 400 | 浅灰辅助色 |

明亮主题中正文显示黑色或近黑色，深色主题跟随前景变量使用可读的浅色；不得在深色主题硬编码黑字。只有描述默认使用浅灰，不得用浅灰弱化开关名称或把选项字号降到描述层级。选中、禁用、危险等语义态沿用共享控件规则；按用户指定，场景的“联动各边留白”和“移除背景”两项辅助标签使用相同浅灰色，字号仍为12px。

键帽、字幕内容、箭头、图片等实际作品的预览不属于界面标签，保留各自外观和用户设置。

字号、颜色和间距集中定义在 [inspector.css](../internal-plugins/system/presentation/src/components/video-editor/inspector.css)。菜单标题使用 `inspector-panel-title`，小节使用 `inspector-section-title`，选项使用 `inspector-control-label`，描述使用 `inspector-description`。不要重新写局部像素、继承过小的 `text-xs` 或给选项套描述色。

## 控件对齐与间距

- 优先使用共享 [SettingsRow](../internal-plugins/system/presentation/src/components/video-editor/SettingsRow.tsx) 和 [SliderControl](../internal-plugins/system/presentation/src/components/video-editor/SliderControl.tsx)。
- 带说明的开关与选项标题行垂直居中，不能与“标题加说明”的整体区域居中。标题行20px，说明另起一行，间隔4px；开关列与正文间隔12px。
- “高级”与变焦“通用设置”使用同一 [AdvancedSettings](../internal-plugins/system/presentation/src/components/video-editor/AdvancedSettings.tsx) 折叠组件。标题13px，子项12px，说明11px；展开后的正文上留白固定12px，子项间距14px。
- 折叠组初始收起，提供箭头、`aria-expanded` 和键盘操作；收起后子控件卸载。展开状态仅属于当前编辑会话，不写入项目或恢复为旧后台配置。
- 普通内容始终在折叠组前。不得用收起、低透明度或灰字掩盖普通设置，也不得复制一个高级开关到多个区域。

## 滚动区域

所有检查器正文使用 `inspector-scroll custom-scrollbar`，保留 `min-height: 0`、稳定滚动槽和相同内边距。使用细滚动条，定制宽度6px，不显示独立的粗原生滚动箭头；标题与重置按钮不随正文滚动。按键、音频和注释页不能遗漏共享样式。

## 场景与摄像头的内容边界

场景依次提供背景圆角、录屏圆角、阴影和内边距。“联动各边留白”位于“移除背景”前，缺失选择时默认开启；已有明确关闭值继续保留。解除联动时原位置保留“内边距”标题，并在下方展开上、下、左、右四个滑条。场景无“高级”及重复裁剪滑条，裁剪统一在预览的“裁剪视频”窗口中完成；场景重置不改动裁剪范围。

摄像头普通设置提供显示开关、宽高比例锁定、宽高、圆角、阴影和当前摄像头视频文件；不显示整体缩放和重复的开场说明。圆角与阴影不放入高级。位置直接在预览中拖动，不提供水平、垂直或距画面边缘滑条。高级保留屏幕变焦联动、镜像与摄像头素材区域裁剪。隐藏旧入口不清空已有素材、坐标、边距或项目参数。

摄像头无片段时只显示空状态和导入入口，不显示当前文件、外观及高级控件，重置禁用。删除最后一段撤下整轨并解除项目素材引用，磁盘原件保留，撤销恢复。变焦光圈只在开启景深时出现；关闭景深保留参数。时间尺与留白定位保留选区及检查器，不能通过清空所有片段选择将侧栏切回场景。

## 验收与后续修改

各分类重置使用固定出厂模型，具体值和保留范围见[默认值与重置](presentation-editor-defaults.md)。不得用上个项目的偏好作为重置目标；摄像头重置保留素材、时长和剪辑，场景重置保留裁剪。

使用源码 Electron E2E，在实际插件正文中验证明暗主题、窄窗口、完整滚动、计算后的字号/颜色、开关与标题对齐，以及折叠正文的12px留白。截图只取插件 WebContentsView 的当前可见区域，先等待正文稳定。

涉及设置参数或导轨时，同步检查预览、项目保存以及连续撤销和重做；一次手势只占一步历史，纯展开、收起和选择不消费历史。界面改名同步教程与当前规范，不能回写历史条目冒充过去已经验收。

所有类型片段选中后均暂停定位起点；重复左键选择同样生效，已选片段右键保留浏览游标以便分割/粘贴。关联效果与独立媒体遵循[时间轴关联规则](presentation-timeline.md)，渲染过程不得补长短效果或移动独立声音。
