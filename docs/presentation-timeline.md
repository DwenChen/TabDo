# 演示时间轴关联规则

录屏按顺序连续排列。片段选中后暂停并定位到当前片段起点，包括录屏、摄像头、声音、变焦、字幕、普通注释和按键；重复左键点击也重新定位。点击或拖动时间尺只浏览时间，保留选区和检查器。已选片段的右键只打开操作菜单，保留随后设置的分割或粘贴位置；右键其他片段会先选中并定位。新增或跨轨选中片段时，时间轴滚动到能看见该片段的位置，不改变显示比例。

## 轨道关系

| 内容 | 时间依据 | 编辑录屏后的行为 |
| --- | --- | --- |
| 变焦、普通注释、按键注释 | 当前覆盖的录屏画面区间 | 随保留画面移动；跨切口的部分分别映射，只合并相邻区间，分离部分拆成独立片段。保留每部分的倍率、镜头、内容和样式，不把中间无关画面补进效果。 |
| 字幕、鼠标轨迹 | 原始素材时间 | 按每个录屏片段的源起点和速度投影。跨切口字幕按当前画面分段，同一源画面重复使用时会再次显示其字幕和鼠标轨迹。修改字幕正文影响该源字幕的各个可见投影。 |
| 已独立编辑的系统声音、麦克风、导入音频 | 独立时间轴起点、源起点与速度 | 移动、裁剪、变速、删除或插入录屏均不修改声音片段；声音通过自己的片段操作编辑。 |
| 摄像头 | 独立时间轴起点与源起点 | 不跟随录屏编辑移动或裁剪，通过自己的片段操作编辑。 |
| 尚未分离的录屏原音 | 所属录屏片段的源时间 | 随所属画面裁剪、重排和变速；伴随导入的系统声音与麦克风已是独立音频。 |

独立音频和摄像头超过成片尾部的部分保留在项目模型中，当前预览和导出只使用成片时间范围；再次延长录屏时仍可使用保留部分。时间轴渲染不修改片段，不在重排后自动扩展短变焦或拉动声音来适配录屏时长。

预览停在全片终点时，屏幕与摄像头共同保留末帧；这是终点画面取样，不会延长任何素材或改写项目。内部切口仍使用左闭右开的时间范围，已结束的较短相机片段和已删除片段不会在结尾恢复。

## 操作边界

- 分割录屏只分割画面，效果在原时间保持连续；随后重排时才按各段保留画面映射。被裁掉或删除的画面不再携带变焦、普通注释和按键注释，全部被删的效果一同移除。
- 录屏变速按源时间映射关联效果，效果持续时间随覆盖画面的播放时长变化。分割产生的短段即使小于手动拖动的最小时长也保留真实区间，不能自动拉长造成相邻重叠。
- 插入视频时只为录屏及关联效果留出位置；跨插入点的效果拆为前后两段，新画面不继承原效果。复制粘贴录屏仅复制该录屏及其原音设置，不额外复制已创作的变焦或注释；源字幕和鼠标轨迹按源画面自然再次投影。
- 单独移动、裁剪或删除变焦、注释、声音、字幕或摄像头，不移动其他类型的轨道。轨道标题排序只改变显示顺序，不改变媒体时间。
- 新增和粘贴注释共用空闲导轨分配：优先使用请求导轨，重叠时使用后面的空闲导轨，非重叠区间可复用。文字、图片、箭头、模糊、马赛克、聚焦和按键各有对应图标。新注释自动滚入可见区域。
- 每次编辑手势沿完整项目历史保存，撤销、重做及重开使用同一组片段；纯选中和浏览时间不产生历史。

检查器遵循[统一UI规范](presentation-inspector-ui.md)，镜头参数见[变焦镜头](presentation-zoom-camera.md)。回归分组为 `presentation-timeline-effects`，实际执行结果记录在当轮维护条目中。
