# 演示变焦镜头

“变焦”沿用原缩放轨道、片段身份与自动跟随能力。新增片段默认二维、1.5×；旧项目的六档倍率继续按原映射读取，既有焦点、自动/手动取景和时间区间不变。

## 操作

在变焦轨道空白处点击添加片段，选中后打开“变焦”侧栏；所有类型的片段选中后均暂停并定位到起点，重复选择也生效。手动点击或拖动时间尺只浏览时间，保留当前选区和检查器。倍率滑条支持1–5×、步进0.01。镜头模式提供2D和3D镜头；取景方式的自动/手动分别控制跟随光标和固定取景。

“视频倍速”和“镜头动画倍速”都按当前片段设置，范围 0.25–4×，默认 1×。视频倍速作用于片段覆盖的时间，和原有录屏片段倍速相乘。预览进度和导出时长反映变速结果，时间轴仍按原编辑位置显示。镜头动画倍速控制 2D 和 3D 镜头的放大及缩回时长，沿用相邻镜头的连接设置。

片段显示“2D/3D · 倍率”和“自动/手动”。悬停说明保留完整名称、起止时间、时长；3D镜头还显示水平/俯仰角度、焦距、景深和反光状态，开启景深后增加光圈与对焦位置。录屏重排后，变焦仅覆盖实际关联画面，分离部分独立成段；其他轨道的处理见[时间轴关联规则](presentation-timeline.md)。

3D镜头提供可拖动的角度板、正面/向左/向右/俯视/仰视/斜向六种预设，以及水平和俯仰角度滑条（各±45°）。焦距18–200mm。开启景深后才显示光圈（f/1.4–f/22）与对焦选项，可以点按或拖动对焦板，并通过水平/垂直滑条精确调整对焦点；较小f值增加虚化，关闭景深保留已设光圈和焦点，屏幕反光可独立关闭。切换回2D会保留3D参数，再次切换可继续编辑。参数按片段独立保存。

“通用设置”沿用统一折叠组，默认收起，提供连接缩放和运动效果。右上角重置恢复当前片段的2D、1.5×与默认跟随，并恢复通用运动参数；当前区间、取景焦点、其他片段和素材不变。一次指针手势只占一次撤销；纯选中与展开不占历史。

## 渲染与项目兼容

变焦期间，录制光标的热点随画面移动，光标图形及点击反馈小幅增大。实际镜头倍率每增加 1×，屏幕上的图形尺寸增加基准尺寸的 6%。预览与共用帧渲染器的导出使用相同规则。

开启“连接变焦”后，可通过“变焦衔接最大间隔”设置相邻片段之间允许的最大空白时长，范围0–5000ms，缺省1500ms。空白时长小于或等于设定值时连接两段，超过则分别进出场；重叠或相接按零间隔计算。关闭连接保留已设间隔。参数沿现有项目保存、预览、导出和撤销重做链生效。

连续倍率使用可选`scale`字段，缺失时读取原`depth`映射；镜头使用可选`camera`字段，缺失时为二维。读取项目时校验非有限值、角度、倍率和光学范围。剪辑移动、分割与复制保留片段镜头设置，项目保存、重开和撤销重做沿现有完整编辑模型运行。

预览及标准、现代导出器共用屏幕平面的透视投影与光学滤镜，同时提供WebGL和WebGPU实现。镜头围绕当前取景中心观察完整录屏平面，保留运镜需要的画外录屏内容，最后按成片视口输出；不能先将放大局部裁成画幅，再把局部作为独立卡片旋转。深度放大且镜头仍在录屏内部时，画面保持铺满；镜头真正看到录屏边缘时，才自然露出原场景背景，不复制边缘像素或额外填底。

焦距改变透视，景深依据旋转平面的相对深度和对焦位置计算；录屏本身仍是一个平面，不生成物体背面或场景深度模型。画外采样按逆投影范围限制，运动模糊输入使用同一范围；最短焦距和极端角度跨越消失线时，最多保留完整原场景。相机进出场共用现有变焦时间权重，相邻镜头沿连接窗口混合。字幕、注释和人像继续作为成片叠加层。

滤镜仅属于当前预览或导出实例；退出效果、切回二维和会话销毁时释放，不保存跨项目GPU缓存。界面遵循[演示编辑侧栏UI规范](presentation-inspector-ui.md)，默认与重置边界见[默认值清单](presentation-editor-defaults.md)。
