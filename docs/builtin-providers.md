# 内置提供商与工具

提供商配置位于设置中的“提供商”，所有入口共享 `provider-settings`。内置工具标识保持 `system`；已安装列表隐藏随包的 `setting` 和 `system`，不删除安装记录、用户配置或第三方插件。设置保持默认独立窗口；工具默认嵌入主窗口，使用专属的会话资源释放机制，不依赖通用退出开关。一次迁移撤回旧版对工具的自动分离和通用退出默认值，保留其他插件配置；内置插件隐藏右上角插件行为设置入口。

## 配置与使用

| 页面 | 能力             | 配置                                                                                        |
| ---- | ---------------- | ------------------------------------------------------------------------------------------- |
| 翻译 | 离线翻译引擎     | Bergamot 英译中，单次最多 1000 字符，启用下载约 55 MB，支持删除资源                         |
| 翻译 | 在线翻译服务     | 百度、谷歌、有道、微软共用一个下拉栏目，分别保留启用状态和默认选择；百度/有道可直接填写凭据，各服务独立保存源/目标语言（自动识别 → 简体中文） |
| 翻译 | AI 翻译          | 复用 AI 页模型与连接，支持选择模型和提示词                                                  |
| OCR  | 微信离线OCR引擎  | 首次启用下载约 35 MB 压缩资源，在本机识别文字与行框                                         |
| OCR  | AI OCR           | 仅启用开关，自动复用 AI 页首个已启用且支持图片输入的模型，无独立连接或模型配置              |
| OCR  | 离线公式识别引擎 | 首次启用下载约 264 MB ONNX 运行组件及模型，输出 LaTeX                                       |
| OCR  | AI 公式识别      | 复用 AI 页视觉模型，可选择模型及提示词                                                      |
| OCR  | 图片上传通道     | 可选 img.scdn.io 上传，默认关闭；开启后上传图片再向 AI 发送 URL，失败回退直接发送           |

工具提供图片文字识别、公式识别及最近一百条识别记录。图片支持面板图片/文件、选择、拖入与粘贴。文字识别保留原图行框，支持坐标明细、双向悬停高亮、整行选择及图上拖选片段，缩放时标注随图片等比变化；未返回坐标的 AI / 第三方 OCR 仅展示原图与文本，不生成虚假行框。截图继续由原截图子组件提供。

识别成功后可点击“翻译”，使用提供商页启用的翻译服务及其源/目标语言设置（离线引擎仅英译中）；默认选择当前有效的默认翻译服务，也可在结果区切换。优先翻译图上选文，无选文时翻译当前完整识别文本，译文单独显示并支持复制/粘贴。换图、编辑原文、更换服务或选文时撤销旧译文；取消或退出后迟到结果不能回填。工具已移除独立文本翻译、代码命名和图片识别并翻译入口；翻译提供商与公共 API 保留供识别后的翻译、面板和插件调用。旧文本/代码处理记录保留在存储中，不再显示为可恢复功能。

在线翻译需网络，百度/有道需有效凭据；AI 调用遵循用户的模型配置。离线公式识别沿用上游模型算法，真实测试已观察到系统字体样本误识别；运行与释放验证不代表识别精度达标，复杂公式需人工核对。

## 兼容与生命周期

参考固定上游源码 `ae2bd2cc678b743f7683c3fb40b6606940acc3d1` 的 f-provider，MIT 来源与适配说明位于 `resources/providers/README.md`。保留原 f-provider 安装与命名空间，首次接管时复制可复用翻译/AI 公式参数并映射启用、默认提供商标识。AI OCR 改为直接复用宿主配置，不带入旧的独立模型选择。旧提供商贡献和重复指令停止出现在聚合列表；旧文字/公式快捷入口转向工具对应子组件，原截图入口只打开识别界面。已移除的 translate、code-translate、ocr-translate、screen-ocr-translate 旧入口直接返回说明，不会恢复独立翻译或自动识别翻译流程。

下载目录为当前数据根目录的 `builtin-providers`；Bergamot 使用同一隔离根下的 `bergamot-translation`。E2E 不读写真实 `~/.tabdo`。微信/公式 ZIP 使用固定 v1.1.1 release 与 SHA-256 摘要，验证必需清单后发布；失败或取消清理暂存目录。删除资源先停用并结束本引擎请求，保留用户配置与其他引擎数据。

原生 OCR、公式与在线翻译使用按次独立 Electron Node 进程。返回结果前结束本次进程树，清理临时图像；页面退出通过生命周期取消所属请求，旧会话不能中断新请求。AI 请求由宿主协议适配器执行并响应取消。Bergamot 每次推理结束释放 Worker，不把启用状态作为常驻模型缓存。后台复制/粘贴登记完整必要任务，剪贴板全局采集继续运行。

## 验证入口

常规源码验证：`pnpm test:regressions providers`，含归档损坏/取消/删除隔离、提供商停用、AI 复用与进程树释放。`builtin-providers.spec.ts` 覆盖设置独立窗口、工具默认嵌入及退出释放；手动分离仍由宿主回归覆盖。

真实模型测试：先在私有目录准备 v1.1.1 的 `native-win.zip`、`latex-ort-win.zip`、`latex-models.zip`，将 `TABDO_MODEL_TEST_ASSETS` 指向该目录，再执行 `pnpm test:e2e tests/e2e/builtin-models.spec.ts`。测试在临时数据目录中安装、推理、删除并保存实际识别结果；未显式准备归档时跳过，不能记为精度或运行验证通过。E2E 直接加载源码，不使用打包产物。

## 选区翻译与识别界面

“通用设置 → 超级面板 → 选中文本自动翻译”单独控制弹窗顶部译文，默认保持启用；关闭不影响提供商或识别页主动翻译。关闭、退出或换选区后迟到译文不再发布。在线服务的源语言默认自动识别，目标语言默认简体中文；显式 API 调用语言优先于保存配置，不再按中文内容自动改为英文。

识别页使用图片与结果双栏，保留图上选文、逐行坐标、缩放、换图取消和历史；小窗口自动上下排列。公式结果增加受限 KaTeX 实时预览，以及源码、行内和独立公式格式复制。
