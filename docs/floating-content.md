# 悬浮内容与会话规范

本文规定 1.2.0 的便签、悬浮图片、图片标记和悬浮中转行为。修改这些窗口前，先读 [工具开发规范](tools-development.md)。用户操作见 [本地图文教程](usage-guide.md)，临时常驻 API 见 [插件规范](plugin-development.md#用户临时常驻)。

## 窗口用途与所有权

| 窗口或能力 | 用途                             | 所属资源                         |
| ---------- | -------------------------------- | -------------------------------- |
| 便签       | 编辑临时文字、调整外观、贴边收起 | 当前便签窗口与正文               |
| 悬浮图片   | 按原图比例查看图片               | 当前图片窗口与图像               |
| 图片标记   | 对图片绘图和添加文字             | 当前标记窗口与编辑状态           |
| 悬浮中转   | 临时收集文本、图片和文件         | 当前中转窗口、条目与私有图片副本 |
| 临时常驻   | 用户保留当前工具或插件独立会话   | 当前插件 WebContents 的运行状态  |

独立内容窗口只接收纯内容和有限操作，不持有父工具页面、Vue 模型或旧列表。父页面退出后，可见的内容窗口继续使用；内容窗口自身隐藏、最小化或关闭时清理。录屏控制条另按 [媒体工具](media-tools.md) 的停止和封装链处理。

临时常驻不改变上表中便签、图片和中转内容窗口的退出规则。支持该能力的工具或插件由宿主显示开关，用户开启后保留独立会话，取消时关闭该会话。状态默认关闭且不落库，开发者只声明支持，不自行放置开关。

## 悬浮中转

### 入口与追加

- 普通指令为“悬浮中转”，功能码 `floating-relay`，匹配文本、图片和任意文件。原“悬浮文字”功能由中转承接，旧 `text-list` 载荷仅作兼容。
- 剪贴板条目提供“悬浮中转”，右侧入口位于“复制并粘贴”下方。多选时显示数量和转交状态；空入口只打开窗口。
- 初次只显示明确转入的条目，不读取全部剪贴板历史。窗口打开后，宿主新采集的复制内容可追加；无分类页。
- 图片使用小缩略图，点击放大。图片的“悬浮固定”和“标记图片”仍进入各自窗口。

### 选择、复制与排序

| 操作       | 要求                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------- |
| 勾选       | 左侧整列覆盖条目高度，支持 Ctrl 切换、Shift 范围选择；该区域不能触发拖出                       |
| 全选       | 中转内 Ctrl+A 全选，再按一次取消全选                                                           |
| 复制与拖出 | 按显示顺序处理同类型选择；混合文本、图片、文件时，在宿主写入前拒绝并反馈，不能静默丢弃部分内容 |
| 文本       | 多条按空行连接；拖出使用标准纯文本拖放                                                         |
| 图片与文件 | 单张图片按图片复制，多张图片复制为文件集合；图片和文件拖出使用宿主原生拖放                     |
| 时间排序   | 从新到旧时追加顶部，从旧到新时追加末尾                                                         |
| 手动排序   | 删除按钮左侧提供手柄；同时支持 Alt 拖动正文、上移/下移和 Alt+方向键                            |

手动排序继承当前可见顺序，之后新复制追加末尾；用户仍可切回时间排序。正文负责外部拖出，手柄负责内部排序，不增加额外的拖出图标。目标应用是否接收文本或文件拖放，需要实际交付验证。

### 删除、反馈与清理

逐条删除和清空仅释放中转条目、容量与所属临时图片，不删除剪贴板历史或原文件。关闭后重新打开为空窗口。清空前的迟到采集不能把旧条目重新追加，新复制仍正常接收。

结果提示约 3 秒、禁止提示约 4 秒后清除；再次触发时重新计时，退出时释放计时器。初始化追加有序排队，容量限制为 1000 条、64 MiB，超限明确反馈并保留已有内容。

主进程校验 sender、所属会话和条目标识，不能让页面直接提交任意文件路径进行原生拖放。窗口关闭后解绑采集订阅并销毁私有副本，不能停止宿主全局剪贴板采集。

实现入口：`src/main/core/toolsTextFloat.ts`、`src/main/core/clipboardEvents.ts` 和 `resources/tools-text-float*`。

## 便签与贴边色签

便签用于窗口内编辑，不保存或恢复正文历史。默认字号 14 px，手动输入范围为 12–32 px；允许清空重输，在编辑完成后校验，仅影响当前窗口。右上角提供撤销、重做，正文右键只提供剪切、复制和粘贴。

全部便签关闭后重置编号与轮色；仍有便签时继续递增。剪贴板的中转操作不向便签追加。兼容的文本追加仍选择最近聚焦的存活便签，目标收起时先展开；不能缓存或重新打开已关闭页面。

### 收起与展开

- 贴边色签和展开纸张属于同一个可见窗口，只改变客户区尺寸并保留完整纸张大小，不复制正文。
- 标题栏采用受控拖动，宿主校验 sender、坐标和纸张尺寸；接近或越过工作区边缘都应识别。拖动释放且尺寸稳定后立即收起，不等待指针离开。
- 指针悬停不自动展开。点击色签或将其拖离边缘才展开；解除后需要再次拖动才重新贴边。
- 收起色签可沿所属边缘移动。贴靠开关只作用于本次运行的整组便签；关闭时解除贴靠并恢复纸张，不写入配置。
- 收展使用分帧缓出和淡入过渡。共享观察器只在独立窗口存活时运行，最后一个窗口关闭后停止。

### 相邻整理

同屏同边的相邻色签在释放拖动后按编号自然排序。轻微错位只允许重叠留白，正文和编号不得被其他窗口遮住；远处色签保留原位置，工作区不足时向内分列。整理只改变位置，不改正文、编号或展开尺寸。

## 悬浮图片与图片标记

悬浮图片按原图比例锁定尺寸，禁用原生边缘缩放。拖动时保留图片相对原点，窗口跟随图像，不产生多余透明区域。

图片标记按 `edit` 意图区分入口，普通悬浮图片不响应绘图快捷键。便签和图片界面的复用范围见 [来源说明](../resources/tools-floating-ui.md)。独立窗口 preload 只开放所属窗口的有限操作，校验调用者，不向页面开放 Node 或任意导航。

## 验证

按改动选择 `floating-relay`、`relay-feedback`、`floating-pointer` 或 `clipboard-interactions` 回归组，并先用 `--list` 确认范围。

必须覆盖真实入口、初始化与新复制追加、选择和手动排序、混合类型拒绝、删除清空、关闭后重开，以及历史和原文件保留。拖放测试检查接收窗口实际收到的文本或文件；不能用已设置标志替代交付结果。

便签另验窗口内编辑、贴边命中、自然编号、色签不遮挡文字和最后窗口关闭后的资源释放。DPI、多屏、原生材质与外部接收应用的差异单独记录，历史通过结果不代替本轮执行。
