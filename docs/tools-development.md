# 内置“工具”子组件开发必读

修改或新增 `internal-plugins/system` 子组件及其宿主能力前，必须先阅读本文。插件标识固定为 `system`；子组件共用插件入口，但临时资源必须属于各自的会话或任务。

## 生命周期与资源归属

- 返回搜索、切换插件、隐藏或最小化宿主、刷新主界面，以及独立窗口关闭/隐藏/最小化，均视为当前工具会话退出。窗口只是失焦但仍可见（例如打开菜单、开发者工具）不视为退出。
- 宿主立即将旧工具视图移出缓存，调用 `window.toolsLifecycle.dispose()`，随后销毁旧 WebContents。再次进入创建全新会话；旧异步结果只能操作旧会话，不能按插件路径查找并关闭新会话。
- 子组件必须使用预加载创建的 `window.toolsLifecycle` 登记资源。查询、监听、定时器、Vue effect、Worker、模型/推理会话、图像/张量、对象 URL、临时缓存与子进程都必须有明确清理器，创建后立即 `addCleanup()`；异步加载完成时也要登记，已退出会话会立即释放迟到资源。
- `dispose()` 首先发出 `signal.abort`，立即执行前台清理。异步读取在每次 `await` 后检查信号或请求版本，禁止回填旧界面、重新注册监听、抢焦点或重新弹窗。组件卸载必须停止 effect、解除订阅并释放大对象引用。
- 清理器必须幂等；单个释放失败不能阻断其他资源回收。异步清理应在五秒内完成，超时会记录错误。`delete require.cache` 或丢弃 JS 变量不能代替模型的 `dispose/release`、Worker 的 `terminate` 或进程退出。

## 必须完成的后台任务

已确认的保存、导出、复制/粘贴及必要计算可以继续，但必须在隐藏窗口或首次异步操作前，通过 `runTask()` 登记完整操作链。只读刷新、轮询、预加载和界面动画不属于必要任务，不得借此保活。

```js
// 必须包含全部后续读写，不能在 operation 外继续保存。
await window.toolsLifecycle.runTask(async (task) => {
  const runtime = await loadRuntime({ signal: task.signal })
  task.addCleanup(() => runtime.dispose())
  if (task.signal.aborted) return
  const result = await runtime.compute(input)
  await persistResult(result)
}, 120_000)
```

任务使用自己的作用域，只保留必需资源。前台退出不会中断已经登记的任务；成功、失败或超时都会立即清理任务资源，最后一项任务收束后销毁页面运行时。退出后拒绝新建任务。必须设置合理任务上限（默认一分钟、最长十分钟）；任务必须响应取消信号，不能通过悬空 Promise、无限重试或未追踪的定时器长期保活。串行保存应在排队时登记并捕获前一个队列 Promise，避免退出丢失排队写入或形成自等待。

## 原生能力与独立进程

Windows 截图和取色通过 `resources/tools-native-worker.cjs` 在独立 Electron Node 进程按次加载原生模块，确认、取消、异常或宿主退出后结束进程；宿主等待进程关闭后交付最终结果。截图预抓帧最多保留两秒，未使用时也退出进程。

新增模型或重型原生能力优先使用同类独立进程隔离。必须登记并终止自己创建的整个进程树、关闭 IPC、等待退出；禁止按进程名称批量杀进程。用户主动打开的浏览器、终端和其他外部应用不属于工具运行时，不能随工具退出被结束。系统公共服务不得随子组件关闭：例如剪贴板全局采集由宿主持有，界面释放后继续记录新复制内容，重进时读取持久化历史。

当前本地版交付 Windows；其他平台的原生实现仍须分别验证，不能假设 Windows 的进程回收逻辑自动覆盖其他平台。

## 必须验证的退出路径

运行相关单元测试和 `pnpm test:e2e`，E2E 直接加载 `scripts/preview-main.cjs` 源码并使用隔离数据目录，不为验证打包。至少覆盖：无任务退出后旧 WebContents 销毁；必要任务完成/失败/取消后的资源回收；任务未结束时重新进入不会被旧任务关闭；异步加载迟到不会复活界面；独立窗口隐藏、最小化和关闭；截图/取色进程确认或取消后退出；剪贴板界面关闭期间复制的新内容在重进后可见。

测试不得删除持久化历史、收藏、用户配置或已安装插件来代替运行时清理。同步免安装预览只更新程序资源，使用 `scripts/sync-portable-preview.cjs` 对原有 `data` 和 `legacy` 逐文件比对，保留回滚资源。未经用户明确指示，不 push、不触发云端构建、不发布 release。
