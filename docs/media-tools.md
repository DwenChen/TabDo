# 图片、视频批处理与录屏移植

本轮以用户提供的三个 ASAR 为界面和功能参考，源码入口为 `internal-plugins/system/src/components/MediaBatch.vue`、`ScreenRecorder.vue`，遵守 [子组件开发原则](tools-development.md)。不运行原插件的 preload，不读取外部软件的配置或账号；处理能力接入本项目的受限 IPC 与独立工作进程。

## 入口与布局

批处理沿用原插件三栏：左侧功能、中间参数、右侧文件队列；底部设置、文件夹/清空、开始/取消固定可见。使用统一系统字体、绿色强调色和明暗主题，不重复显示宿主标题。文件行显示缩略图/预览、尺寸、大小、时长、错误与输出入口；合并顺序可调整。

| 入口                    | 功能                                                                                                            |
| ----------------------- | --------------------------------------------------------------------------------------------------------------- |
| 图片批量处理            | 压缩、格式转换、尺寸、水印、圆角、边框、填充、裁剪、旋转、翻转、合并图片/PDF/GIF、手动裁剪；支持文件与图片匹配  |
| 图片文件夹处理          | 递归读取支持图片，不跟随符号链接                                                                                |
| 图片手动裁剪 / 图片合并 | 直达对应操作，裁剪框映射原图像素，合并按队列顺序                                                                |
| 视频批量处理            | 压缩、截取、比例裁剪、转换、GIF/WebP、水印、尺寸、封面、倍速、翻转、旋转、合并、音频提取/静音/音量/替换、帧提取 |
| 录屏助手                | 全屏、窗口、区域；倒计时、系统声、麦克风、指针，存储目录、标准/高清、点击与按键效果                             |
| 区域录屏 / 停止录屏     | 不闪出宿主的快捷入口，停止等待 MP4 封装和清理                                                                   |

录屏已按用户提供的 2.1.0 重新对照实现，替换上一版简化界面：全屏左侧单列大图，窗口左侧应用图标与名称列表，顶部带图标的三入口；全屏右侧为 3–9 秒分段倒计时和横排声音/操作选项，窗口页不显示倒计时、点击和按键开关。全屏在屏幕中心播放数字倒计时，窗口直接开始。点击区域入口即在真实光标所在显示器打开全屏选区，支持拖动、八方向调整、宽高输入、方向键微调及独立声音/操作工具栏，**确认后才开始**，Esc/失焦取消。保留上次选区尺寸配置，不缓存截图。

录屏设置依原版使用右侧抽屉：系统目录/自定义存储位置、标准/高清、左右键独立颜色/Emoji 卡片与恢复默认、屏幕取色、五种键帽样式预览与九宫格位置。键帽和左右键效果实际录入视频，设备勾选只枚举设备，不保留媒体流。开始时自动命名保存到设置目录，不再弹保存对话框；停止等待封装和排他发布后定位结果，真正退出宿主时只保存。控制条继续保持用户要求的 **12px 圆角矩形**、透明四角与可拖动；首次显示前排除捕获，区域模式优先避让录区。输入效果复用宿主既有全局输入管理器的专属订阅，结束只撤销自己的订阅。原插件的会员/账号入口不移植，布局按统一字体、绿色强调色和明暗主题适配。

## 文件与任务边界

- 保留原文件；图片和视频各自设置输出方式，**默认与源文件同级目录**，每个文件分别写入自己的父目录。合并使用队列首个文件的目录；剪贴板图片没有源路径，回退到下载目录。自定义目录仍可选择并独立记忆，不删除旧路径配置。同名结果自动编号，以独占创建发布，不覆盖既有文件。
- `mediaProcessor.ts` 在首次异步操作前登记请求、所属 WebContents 和完整收尾 Promise。读取上限两分钟、处理上限十分钟；前台读取随退出取消，确认的处理由 `runTask` 持有，收尾后销毁旧页面。
- `media-worker.cjs` 按次启动 Electron Node，Sharp、PDFKit、GIF 与 FFmpeg 不加载到宿主常驻进程。同级目录输出由工作进程向宿主申请对应输出卷的自有暂存区，宿主在首次目录准备时登记 Promise；目录准备、取消和正常收尾均等待并清理全部自有目录，避免不同磁盘或多个源目录下遗留。取消只终止所属进程树；完整发布的结果保留。硬链接不受支持时使用排他复制，不覆盖已存在的文件。
- 最多 1000 文件、递归深度 20、图片画布 6400 万像素、GIF 累计 3200 万像素、视频提帧 500 张。FFmpeg 仅接收按操作构造的参数数组，不接受任意命令或网络输入。
- 图片输出支持 PNG/JPEG/WebP/TIFF/AVIF/GIF/BMP/ICO/SVG；SVG 为内嵌栅格图。动画压缩/转换按格式能力保留帧，几何操作明确处理首帧。HEIC 依赖实际编解码器，未以真实文件验收，无法解码时逐行报错。
- 视频合并默认统一尺寸、帧率和音轨，缺音轨补静音；不重编码仅适用兼容来源。封面仅支持 MP4/MOV。特殊编码格式、声音设备、多屏/DPI、旧 Windows 和不支持硬链接的输出文件系统保留人工验收。

`scripts/media-runtime-dependencies.cjs` 收集三项生产依赖的完整版本树与许可，免安装同步时物理展开，避免遗漏间接依赖，不改 `data/legacy`。`media-tools` 回归组验证真实图片像素、PDF/GIF、视频输出、不可覆盖发布、取消和依赖展开；源码 E2E 验证三栏、主题、处理及旧页面释放。实际结果和失败修正写入当轮历史。
