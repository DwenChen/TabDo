# 演示编辑器默认值与重置

“变焦”侧栏提供连续倍率和2D/3D镜头。新增片段默认2D、1.5×；3D镜头首次开启使用斜向角度，未保存参数的焦距50mm、光圈f/2.8、景深及反光关闭、对焦点居中。当前变焦重置会清除连续倍率覆盖与3D镜头，恢复2D、1.5×；仅切换2D/3D则保留光学参数。范围与兼容行为见[变焦镜头](presentation-zoom-camera.md)。

新录制和新导入素材使用出厂编辑参数。场景、光标、摄像头、字幕和轨道排列不继承上个项目；打开已有项目继续恢复该项目保存的参数。自动添加变焦的开关、字幕引擎路径、自定义壁纸和已保存预设属于应用偏好，继续保留。

出厂模型由 [editorDefaults.ts](../internal-plugins/system/presentation/src/components/video-editor/editorDefaults.ts) 创建，基础校验复用 [projectPersistence.ts](../internal-plugins/system/presentation/src/components/video-editor/projectPersistence.ts)。分类重置使用同一模型，不能调用 `loadEditorPreferences()` 把上个项目的外观当作默认值。重置只影响当前项目和指定分类，一次点击占一步历史；保存后重开应保持重置结果。

| 入口                  | 重置后的选项值                                                                                                                                     | 保留范围                                                       |

| 光标右上角“重置”      | 显示开启、循环关闭、Tahoe样式；大小2.5、平滑0.67；点击效果无、颜色`#2563EB`、大小1、透明度1、时长600ms；点击弹跳2、弹跳时长350ms、摆动0.4          | 已录制轨迹、按键、变焦及其他分类；同时清除本会话的光标显示覆盖 |

| “裁剪视频 → 重置裁剪” | 位置(0,0)、宽高(1,1)，完整素材；自由比例；退出重新框选                                                                                             | 场景及其他分类；“取消”回滚到打开弹窗前，“完成”后进入项目历史   |

录屏、注释和片段右键菜单没有独立的“恢复出厂”入口；复制、粘贴、分割、删除及音频“恢复音量”按各自操作执行。“恢复音量”只恢复音量，不重置响度与淡入淡出。应用快捷键由宿主“快捷键”管理，六项演示动作缺省关闭，不随项目重置。

摄像头无片段时重置禁用；删除最后一段解除当前项目素材引用并撤下轨道，保留磁盘原件和撤销恢复能力。分类重置不得重新执行旧项目迁移，不能改变独立音频、已删除音轨或原始音频隐藏状态；曾被旧重置错误显示的已独立编辑来源在读取时统一撤下虚拟音频条。

## 变焦与光标的通用默认参数

按键重置恢复统一键帽大小100%、连接相邻输入开启及800ms分组最大间隔、进入及退出效果均为无；文字、键帽和显示框一起恢复标准大小并保留组中心。动画时长缺省280ms，仅启用效果后显示。普通注释缺省矩形遮罩、无进出场动画；手绘和动画的当前编辑值随项目保存，详见[预览、按键与注释](presentation-visual-effects.md)。

| 参数                   | 默认值                                                                 | 所属重置 |
| ---------------------- | ---------------------------------------------------------------------- | -------- |
| 变焦进入/退出时长      | 1522.575ms / 1015.05ms                                                 | 变焦     |
| 变焦进入重叠           | 500ms                                                                  | 变焦     |
| 连接最大间隔/过渡时长  | 1500ms / 1000ms                                                        | 变焦     |
| 进入/退出/连接曲线     | recordly / recordly / glide                                            | 变焦     |
| 相机弹簧刚度/阻尼/质量 | 1 / 1.13 / 1.12                                                        | 变焦     |
| 平滑度/经典模式        | 0.5 / 关闭                                                             | 变焦     |
| 变焦运动模糊           | 0.35；平移/变焦阈值0；方向模糊41.8px、径向强度1；响应11/9、安全半径6px | 变焦     |
| 光标弹簧刚度/阻尼/质量 | 0.92 / 1.36 / 1.29                                                     | 光标     |
| 光标运动模糊           | 0.6                                                                    | 光标     |

## 验证

`presentationDefaults` 单测检查默认模型隔离与分类边界；`presentation-defaults` 源码 E2E 使用真实宿主、隔离资料、项目文件与鼠标，检查重开后的整轨拖动、默认值、逐栏重置和撤销重做。相邻按键、音频、裁剪及明暗主题由轨道和检查器专项共同验证。回归入口见 [TX-121](../tests/regressions/README.md#tx-121-演示新项目默认值分类重置与重开拖轨)。
