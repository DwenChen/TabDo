# 设置开发规范

设置侧栏的[呼叫AI](call-ai.md)提供逐项保存。Skill 与 MCP 列表各自管理启用状态，添加按钮居中并跟随通用设置的主题色。全局规则、网页搜索和运行时分组折叠，Brave Search 密钥使用系统加密存储，搜索和抓取须在聊天窗开启。结果产物清理保留原生二次确认，只清理工具登记的当前默认位置子目录。

呼叫AI的聊天权限模式按本机配置保存。首次使用请求批准，后续窗口恢复上次选择，完全权限由原生对话确认并用红色盾牌提示。类似命令的批准随当前窗口关闭而撤销。

演示“变焦”沿用原缩放片段设置入口，增加2D/3D模式、连续倍率、角度及光学参数；数据属于当前片段，切换2D保留3D参数，分类重置恢复2D及1.5×。界面和渲染细则见[变焦镜头](presentation-zoom-camera.md)。通用设置仍默认折叠。

修改设置插件、宿主快捷键、首次启动默认值、托盘或数据路径前必读本文，并结合 [维护流程](maintenance.md)及 [数据备份与迁移](backup-and-migration.md)。

## 页面与裁剪边界

演示编辑侧栏的文字层级、折叠留白、开关对齐和滚动条必须遵守[专用UI规范](presentation-inspector-ui.md)，不得在单个检查器另建样式。场景的留白联动位于移除背景前，解除联动仍保留内边距标题；裁剪只在预览弹窗中操作，场景重置不改动裁剪范围。

通用设置首先展示超级面板，其后是剪贴板快捷匹配、数据与缓存目录、基础、外观、终端、行为、网络及开发者选项。开发者使用初始闭合的折叠组。行为不提供工具窗口位置策略和“插件默认高度”，窗口位置与默认尺寸由子组件、插件清单的 `window` 配置决定；“行为”只保留用户可控的“记住子组件窗口大小”，默认开启，仅作用于开发者允许调整的窗口。开发者组不再提供开发者工具位置与内部 API 授权插件；这些入口移除后由宿主保留默认值，不恢复旧主搜索窗口的呼出说明。

所有应用快捷键设置统一放入侧栏“快捷键”，默认进入“内置快捷键”。设置页呼出快捷键说明必须明确：从其他应用打开 TabDo 应用设置页；全屏暂停快捷键同属该组。新增快捷键不得混入通用设置。标准文本编辑及插件内部交互按键不属于应用级快捷键开关。

默认窗口尺寸下，描述文字应让出控件空间，操作按钮不得被压缩到逐字换行；秒数等短数值采用紧凑输入框。复制后匹配时限的说明不固定指称中键，最近复制内容的回退匹配适用于当前配置的超级面板触发键。子组件正文默认高度由清单声明或回退 `mainWindowLayout.ts` 的 `DEFAULT_PLUGIN_HEIGHT`（540），表单不再提供全局高度覆盖；历史 `windowDefaultHeight` 字段只作数据兼容保留，不再应用。

先通过布局避免正文重叠：固定导航与滚动列表占用独立区域，整页详情显示时撤下旧正文和旧导航，并在离场过渡开始时隐藏旧页。此类页面继续使用 `--bg-color` 或透明留白，跟随 Mica/Acrylic 的原生材质；不能为防透字而铺满固定实色，造成聚焦时突兀、失焦时才融合的色块。

真正覆盖其他内容的下拉菜单、提示消息、对话框及仍需叠放的吸顶表头使用不透明 `--dialog-bg`，渐变和透明语义色叠在实色底上；提高 z-index 或增加模糊不能代替遮挡。明暗主题和三种 Windows 材质均检查聚焦、失焦、滚动与页面切换。WebContents 截图的透明通道不能显示 DWM 的最终材质，须同时验证窗口真实焦点、分区边界及留白透明度，不以不透明检查替代材质融合验收。共享组件和工具窗口的审查范围见 [覆盖层审查](interaction-surfaces.md)。

唤醒黑名单已移除；超级面板的屏蔽应用仍控制鼠标触发。调试日志页、路由、内存收集器及日志内部 API 均已删除，不能只隐藏侧栏后继续后台收集。文件故障日志保留。终端、代理、剪贴板保留天数、窗口材质与“记住子组件窗口大小”仍有实际使用者；裁剪设置前应核对消费者，不能按名称推断无用。

### 统一控件

普通表单输入、下拉触发器和同排按钮使用共享样式：34 px 外框高度、`border-box`、相同字体，以及主题的 `--control-bg` / `--control-border`。数字输入去除原生不透明外观；短数值只调整宽度，不改变高度。

“选中文本自动翻译”只控制超级面板选文译文，默认跳过以中文为主的文字及无文字选区，手动翻译继续使用既有提供商与语言配置。翻译服务的方向图标使用细线 SVG，并对齐两侧语言下拉框中心；说明及判定边界见 [识别与翻译](builtin-providers.md#选区翻译与识别界面)。

关于页的教程、项目、更新和致谢入口统一使用普通 `.btn`，不单独为导航设置绿色实底或另一套尺寸。只对真实叠放的菜单使用不透明表面，页面继续保留材质。验收比较明暗主题、材质模式下的 computed style、尺寸与截图。

## 首次启动与已有偏好

窗口材质仅在配置缺失时按系统初始化：Windows 11 默认“云母”，其他系统默认“无”。宿主、超级面板与分离窗口共用系统判断，不覆盖已有明确选择；设置页缺失值从宿主读取。

- “关于 → 阅读本地教程”提供随包的 16 章操作说明，支持目录、全文搜索和翻页；旧教程路由仍打开此页，不增加侧栏入口，首次启动不自动弹出。
- 教程只展示说明，不创建练习进程、透明覆盖层、模拟服务或桌面样例，不更改工具路径与用户资料，也不自动清理旧版遗留目录。正文与维护方式见 [本地教程](usage-guide.md)。
- 设置页呼出快捷键初始为空，不注册 Alt+Z 等后备值；全屏暂停快捷键初始关闭。自定义全局和应用快捷键列表初始为空。
- `src/shared/shortcutSettings.ts` 仍是宿主读取历史内置快捷键配置的唯一来源。搜索框聚焦、分离、打开设置、关闭/隐藏、终止插件、Esc、开发者工具和 F10 停止录屏不再在“快捷键”页提供条目或写入接口，历史已启用值继续由宿主读取，避免已有用户行为突变。窗口置顶不占用该开关列表：通用设置“基础 → 窗口置顶”是唯一总开关，出现在“唤醒”之后，启用后才显示并可折叠“显示高亮边框”、边框颜色、不透明度、粗细、圆角、提示音与快捷键引导；关闭高亮边框后仍可置顶并播放提示音，但不再绘制边框。展开的“置顶样式与快捷键”不再因点击页面其他位置收起，只在切换到其他设置页或滚动到面板完全离开可视区域时自动折叠，返回本页保持收起。配置保存到 `settings-general` 的 `alwaysOnTop*` 字段，默认快捷键 `Shift+T` 在“快捷键 → 内置快捷键”页修改。边框由原生辅助进程通过 WinEvent 钩子驱动分层窗口绘制，启用注册失败时保留原开关状态并回告设置页；不弹出 TabDo 通知，也不注入窗口标题栏菜单。
- 宿主、插件 WebContentsView、分离窗口及全局注册必须遵守同一开关，切换后立即更新；Windows 不保留可绕过开关的 Electron 默认菜单快捷键。录屏默认通过控制条停止，不能在文案中宣称 F10 始终可用。
- `localEditionDefaults.ts` 只在相应键不存在时初始化：“设置”来源的普通功能与所有类型匹配指令全部列入 `disable-commands`；“截图、剪贴板、便签、文件搜索、录屏、演示录屏、呼叫AI”按此顺序写入 `super-panel-pinned`。
- 已保存的空列表和显式启用/关闭均是用户选择，不能每次启动重新覆盖。重置初始状态是独立动作，每轮都需要用户明确授权，历史记录不能作为下一轮依据。

演示编辑器的播放、变焦、分割、标注、关键帧和删除六项动作统一位于“快捷键 → 内置快捷键 → 演示编辑器”。按键组合保存于宿主的 `presentation-shortcuts`，缺失或空键代表关闭；独立编辑器只读取该配置并及时刷新，不维护第二套快捷键设置。

演示编辑器偏好集中在项目主页“设置”，编辑工具侧栏不重复设置入口；不显示无实际操作的权限分类，设备开启时按需请求权限。“自动为新录制应用变焦”位于通用，不重复快捷键入口；不再提供动态效果分类。选中变焦片段后设置默认开启的连接变焦，并以普通选项“运动效果”的平滑/专注二选一替代经典动画，缺省平滑；运动效果只调整变焦时长，保留光标参数。除场景无高级外，侧栏高级通过普通选项后的“高级”标题展开；变焦“通用设置”使用相同默认收起的折叠布局，右上角只提供当前分类重置。摄像头在预览中直接拖放，通过宽高和比例锁定调整大小；圆角缺省100%，圆角与阴影均位于普通选项，移除整体缩放、位置和边距滑条，重置保留当前素材。背景与录屏视频的圆角分别调整并保存。旧默认运动偏好升级为平滑，已有项目仍恢复保存参数。修改立即影响当前预览和后续导出，项目外观沿项目文件保存；新录制和新导入使用出厂模型，不继承上个项目外观。自动缩放开关、字幕引擎路径、自定义壁纸及已保存预设继续保留。各分类重置值与保留范围见[编辑默认值与重置](presentation-editor-defaults.md)；已有项目重新打开时恢复其已保存参数。所有项目及编辑改动自动保存，不提供重复的手动保存按钮；组件来源和许可统一在应用“关于”中告知。

## 互联服务

侧栏“互联服务”用于配置宿主级的局域网剪贴板同步与文件传输，页面直接读写宿主 `settings-interconnect`，不写入插件命名空间。该页在侧栏中紧跟“呼叫AI”；“我的数据”固定在“关于”之前。只实现 KDE Connect 协议中的剪贴板与文件共享能力，不加载音乐、通知、遥控、短信或 SFTP 等插件，也不恢复桌面端守护进程。

- **运行与身份**：服务默认关闭，由用户在侧栏主动启用后监听 UDP 1716 与 TCP 1716–1764。首次启动生成本机 EC 自签名证书，CN 为 32 位设备 ID，私钥与证书保存在资料根 `interconnect/`。证书损坏重建后会清空旧信任，避免用新身份沿用旧设备授权。页面展示设备名称、本机 ID、证书指纹与实际 TCP 端口，不展示私钥。
- **配对与信任**：已配对设备单独持久化设备 ID、名称、类型、协议版本、证书与指纹；连接时核对证书 CN 与指纹，不一致立即断开。收到对方配对请求时显示在设备区并允许接受或拒绝；可选的“自动接受配对”只在可信网络中由用户主动开启。离线或已失效的已配对条目必须能通过“取消配对”直接移除：仅从持久化信任恢复、本次运行没有设备记录的条目也要撤销信任；本次发现后已断开的条目在撤销信任时同时移除临时记录，避免升级或更换设备后残留无法删除的条目。
- **剪贴板**：默认把本机复制的文本与图片同步到已配对在线设备，收到远端文本时写入宿主剪贴板并登记历史。远端写入期间抑制回声，不把同一条内容再次发回。设置页不提供全局“立即同步一次”，需要时可对单台已配对在线设备使用设备行的“同步剪贴板”。
- **文件传输**：默认接收目录可在页面更改或在资源管理器中打开；接收时按文件名去重避让，不覆盖已有文件，并统一使用接收时间作为文件修改时间。发送时不声明原文件的创建与修改时间，因此非 TabDo 的 KDE Connect 接收端也按自身接收时间落盘，不会还原旧日期。页面提供“系统通知”开关，默认开启；关闭后接收完成、传输失败、配对请求和防火墙等待提示都不再弹出系统通知，设备与面板状态照常更新。设置页只保留上述配置，不再显示发送或接收记录；传输进度、失败原因、重新发起、已接收文件定位和清空记录集中在宿主级“互联传输”面板。
- **互联传输指令**：选中文件或剪贴板图片时发送文件，选中或匹配文本时把当前剪贴板主动同步一次。触发时先广播并等待设备回应；存在多个已配对且可接收文件的在线设备时先弹出目标设备选择，默认设备排在最前并标记，单台设备则直接发送。

“互联传输”只负责启动任务，完成、失败和超时由宿主服务记录；面板对失败的发送任务提供“重新发起”，对已完成任务提供“打开位置”，在资源管理器中高亮本地文件，并可“清空记录”移除已完成和失败的任务记录（不删除文件，进行中的任务保留）。面板由托盘右键“互联传输”或传输任务自动打开，手动打开后不随任务完成自动关闭。首次传输可能触发 Windows 防火墙询问；仅在接收方尚未连入载荷端口时提示放行，接收方一旦连入立即取消提示。未放行的连接在等待超时后记为失败，可在面板直接重发。系统通知受设置页开关控制。不新增常驻工具页面，不把证书、套接字或远端文件路径暴露给渲染进程。

## 托盘与游戏模式

左键托盘打开应用设置，右键保留游戏模式、唤醒、“互联传输”、重启和退出，避免重复的显示/隐藏设置入口。“互联传输”直接打开宿主级传输面板，不经过插件或设置页。唤醒以一级菜单出现，悬停后在二级菜单调整开关、屏幕点亮和持续时间；它必须依赖“显示托盘图标”，开启唤醒会自动打开托盘图标，关闭托盘图标会同时关闭唤醒。游戏模式是免打扰：通过 `dndManager` 暂停设置页呼出/全局指令快捷键及超级面板鼠标触发，关闭后恢复；不调整游戏性能，不停止全局剪贴板采集。

## 数据与验证

TabDo 设置始终使用独立窗口，最小化和失焦时保留当前页面，明确关闭后销毁正文。标题栏提供常规窗口控件。全部工具和必要任务退出、仅剩隐藏宿主后等待10秒解除临时输入引用。Windows工作集超出100MB目标时才归还冷页，已达标时保留热页。打开设置会取消待执行回收，不停止全局剪贴板采集或修改已保存配置。按 [内存与重开体验规范](memory-development.md) 联合验证正文重开速度、真实引用释放及匹配恢复；具体测量见 [性能审查](performance-audit.md#windows-闲时常驻内存)。

“所有指令”搜索自动切换展示来源时，菜单必须使用当前展示来源的规范指令快照，固定、打开与别名操作不得继续引用此前手动选择的来源。快照与正文共用已加载指令数据，避免迟到刷新写回旧来源；固定及取消固定保留其他项目和顺序。

“数据与缓存目录”调整整个 `.tabdo` 资料根，必须使用退出后的迁移链：校验目标、原生确认、停止采集和关闭数据库、复制校验、发布、记录位置、重启。原件保留，禁止在线复制 LMDB、覆盖非空目标或在路径失效时回退为空白配置。程序安装目录会在安装更新时被整体替换，迁移预检与离线工作进程都拒绝落入其中的目标；当前资料已在安装目录内时，更新下载与安装入口必须先拦截并提示迁移。迁移同时写入锚点记录和独立稳定记录 `%APPDATA%/TabDo/.data-location.json`；锚点记录缺失时回退稳定记录，显式 `TABDO_DATA_ROOT` 环境保持隔离。迁移成功后的重启进程由工作进程注入一次性位置，首帧设置页、`userData`/`sessionData` 与日志直接使用新目录；每次启动首行日志记录实际资料与日志目录，便于核对。实现及人工恢复步骤见 [迁移文档](backup-and-migration.md#更改数据与缓存目录)。

`settings-defaults` 回归组覆盖默认值、已有选择、快捷键即时生效、托盘、目录失败边界和真实重启后的插件/数据库保留；Electron 必须从源码启动并同时隔离数据和旧数据目录。界面截图直接捕获设置插件当前可见区域，正文稳定后再截图。默认值修改需回查已有测试的假设，场景需要的快捷键或固定项应由夹具显式设定。

演示编辑器的“按键显示”固定在光标旁，样式沿项目注释保存；按键不再列入普通注释类型。录制到的系统音频与麦克风首次加载即为独立音轨，点击在预览旁分别编辑；名称固定在左侧轨道栏。摄像头素材自动显示独立时间轴轨道，画中画外观保留在侧栏。片段的分割、复制、粘贴、删除及音频静音集中到时间轴右键菜单；剪刀只分割选中片段，侧栏保留参数与画面裁剪。显示比例可手动调整，编辑片段不重新适配全览；游标显示到毫秒。

演示编辑器“文件 → 项目保存目录”使用真实目录选择，验证写入后合并保存偏好。新建项目使用新目录，已有项目继续写入原路径；不搬动录制素材，不覆盖录制目录及已有设备选择。
