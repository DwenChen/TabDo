# 设置开发规范

修改设置插件、宿主快捷键、首次启动默认值、托盘或数据路径前必读本文，并结合 [维护流程](maintenance.md)及 [数据备份与迁移](backup-and-migration.md)。

## 页面与裁剪边界

通用设置首先展示超级面板，其后是剪贴板快捷匹配、数据与缓存目录、基础、外观、终端、行为、网络及开发者选项。开发者使用初始闭合的折叠组。窗口位置指工具窗口，不再使用旧主搜索窗口的呼出说明。

所有应用快捷键设置统一放入侧栏“快捷键”，默认进入“内置快捷键”。设置页呼出快捷键说明必须明确：从其他应用打开 TabDo 应用设置页；全屏暂停快捷键同属该组。新增快捷键不得混入通用设置。标准文本编辑及插件内部交互按键不属于应用级快捷键开关。

默认窗口尺寸下，描述文字应让出控件空间，操作按钮不得被压缩到逐字换行；秒数等短数值采用紧凑输入框。复制后匹配时限的说明不固定指称中键，最近复制内容的回退匹配适用于当前配置的超级面板触发键。插件正文默认高度统一使用 `mainWindowLayout.ts` 的 `DEFAULT_PLUGIN_HEIGHT`（540），表单初值、无效输入回退、主动重置及宿主初值一致；已保存的自定义高度继续保留。

先通过布局避免正文重叠：固定导航与滚动列表占用独立区域，整页详情显示时撤下旧正文和旧导航，并在离场过渡开始时隐藏旧页。此类页面继续使用 `--bg-color` 或透明留白，跟随 Mica/Acrylic 的原生材质；不能为防透字而铺满固定实色，造成聚焦时突兀、失焦时才融合的色块。

真正覆盖其他内容的下拉菜单、提示消息、对话框及仍需叠放的吸顶表头使用不透明 `--dialog-bg`，渐变和透明语义色叠在实色底上；提高 z-index 或增加模糊不能代替遮挡。明暗主题和三种 Windows 材质均检查聚焦、失焦、滚动与页面切换。WebContents 截图的透明通道不能显示 DWM 的最终材质，须同时验证窗口真实焦点、分区边界及留白透明度，不以不透明检查替代材质融合验收。共享组件和工具窗口的审查范围见 [覆盖层审查](interaction-surfaces.md)。

唤醒黑名单已移除；超级面板的屏蔽应用仍控制鼠标触发。调试日志页、路由、内存收集器及日志内部 API 均已删除，不能只隐藏侧栏后继续后台收集。文件故障日志保留。终端、代理、剪贴板保留天数、窗口材质与插件默认高度仍有实际使用者；裁剪设置前应核对消费者，不能按名称推断无用。

### 统一控件

普通表单输入、下拉触发器和同排按钮使用共享样式：34 px 外框高度、`border-box`、相同字体，以及主题的 `--control-bg` / `--control-border`。数字输入去除原生不透明外观；短数值只调整宽度，不改变高度。

“选中文本自动翻译”只控制超级面板选文译文，默认跳过以中文为主的文字及无文字选区，手动翻译继续使用既有提供商与语言配置。翻译服务的方向图标使用细线 SVG，并对齐两侧语言下拉框中心；说明及判定边界见 [识别与翻译](builtin-providers.md#选区翻译与识别界面)。

关于页的教程、项目、更新和致谢入口统一使用普通 `.btn`，不单独为导航设置绿色实底或另一套尺寸。只对真实叠放的菜单使用不透明表面，页面继续保留材质。验收比较明暗主题、材质模式下的 computed style、尺寸与截图。

## 首次启动与已有偏好

窗口材质仅在配置缺失时按系统初始化：Windows 11 默认“云母”，其他系统默认“无”。宿主、超级面板与分离窗口共用系统判断，不覆盖已有明确选择；设置页缺失值从宿主读取。

- “关于 → 阅读本地图文教程”提供随包的 12 章正文与插图，支持目录、全文搜索和翻页；旧教程路由仍打开此页，不增加侧栏入口，首次启动不自动弹出。
- 教程只展示说明，不创建练习进程、透明覆盖层、模拟服务或桌面样例，不更改工具路径与用户资料，也不自动清理旧版遗留目录。正文与维护方式见 [本地图文教程](usage-guide.md)。
- 设置页呼出快捷键初始为空，不注册 Alt+Z 等后备值；全屏暂停快捷键初始关闭。自定义全局和应用快捷键列表初始为空。
- `src/shared/shortcutSettings.ts` 是内置快捷键默认值与读取规则的唯一来源。搜索框聚焦、分离、打开设置、关闭/隐藏、终止插件、Esc、开发者工具及 F10 停止录屏全部默认关闭，只有配置值严格为 `true` 才启用。
- 宿主、插件 WebContentsView、分离窗口及全局注册必须遵守同一开关，切换后立即更新；Windows 不保留可绕过开关的 Electron 默认菜单快捷键。录屏默认通过控制条停止，不能在文案中宣称 F10 始终可用。
- `localEditionDefaults.ts` 只在相应键不存在时初始化：“设置”来源的普通功能与所有类型匹配指令全部列入 `disable-commands`；“截图、剪贴板、便签、文件搜索、录屏、演示录屏”按此顺序写入 `super-panel-pinned`。
- 已保存的空列表和显式启用/关闭均是用户选择，不能每次启动重新覆盖。重置初始状态是独立动作，每轮都需要用户明确授权，历史记录不能作为下一轮依据。

演示编辑器的播放、缩放、分割、标注、关键帧和删除六项动作统一位于“快捷键 → 内置快捷键 → 演示编辑器”。按键组合保存于宿主的 `presentation-shortcuts`，缺失或空键代表关闭；独立编辑器只读取该配置并及时刷新，不维护第二套快捷键设置。

演示编辑器偏好集中在项目主页“设置”，编辑工具侧栏不重复设置入口；不显示无实际操作的权限分类，设备开启时按需请求权限。运动预设立即改变当前项目预览和后续导出，并保存为新项目偏好；已有项目重新打开时恢复其已保存参数。所有项目及编辑改动自动保存，不提供重复的手动保存按钮；组件来源和许可统一在应用“关于”中告知。

## 托盘与游戏模式

左键托盘打开应用设置，右键只保留游戏模式、重启和退出，避免重复的显示/隐藏设置入口。游戏模式是免打扰：通过 `dndManager` 暂停设置页呼出/全局指令快捷键及超级面板鼠标触发，关闭后恢复；不调整游戏性能，不停止全局剪贴板采集。

## 数据与验证

“所有指令”搜索自动切换展示来源时，菜单必须使用当前展示来源的规范指令快照，固定、打开与别名操作不得继续引用此前手动选择的来源。快照与正文共用已加载指令数据，避免迟到刷新写回旧来源；固定及取消固定保留其他项目和顺序。

“数据与缓存目录”调整整个 `.tabdo` 资料根，必须使用退出后的迁移链：校验目标、原生确认、停止采集和关闭数据库、复制校验、发布、记录位置、重启。原件保留，禁止在线复制 LMDB、覆盖非空目标或在路径失效时回退为空白配置。实现及人工恢复步骤见 [迁移文档](backup-and-migration.md#更改数据与缓存目录)。

`settings-defaults` 回归组覆盖默认值、已有选择、快捷键即时生效、托盘、目录失败边界和真实重启后的插件/数据库保留；Electron 必须从源码启动并同时隔离数据和旧数据目录。界面截图直接捕获设置插件当前可见区域，正文稳定后再截图。默认值修改需回查已有测试的假设，场景需要的快捷键或固定项应由夹具显式设定。
