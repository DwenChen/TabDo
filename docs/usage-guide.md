# 使用引导与练习环境

入口位于“设置 → 关于 → 使用引导”，不占用侧栏。全新资料第一次启动直接创建独立练习实例并显示全屏欢迎选择，用户可开始或选择“暂不学习，退出引导”；拒绝后重启不重复弹出。关于中的“开始全屏引导”可随时重进；旧的使用引导路由兼容跳转至关于，已有资料升级不会强制弹出。

引导使用覆盖整个显示器（含任务栏）的透明无边框窗口。镂空按当前可见控件、菜单选项或便签色签的真实矩形聚焦，使用正文客户区偏移和页面缩放映射到屏幕 DIP，持续跟随窗口、滚动与菜单变化。提示卡实测尺寸后避让目标，卡片外鼠标透传给真实窗口。教学目标窗口临时置顶，提示覆盖层在其上方；超级面板按真实鼠标位置打开，不强制移动或夺取焦点。

进入工具教学前关闭隔离实例遗留的设置窗口；正式关于窗口在欢迎页接管后收起、结束时重新打开，不改设置数据。同一主宿主切换工具时按新页面身份重新提升层级，防止旧设置覆盖工具。Windows主工具切到本次教学提示卡时保留前台；转到外部程序仍执行原有失焦隐藏行为，退出撤销本次焦点登记。验收同时检查 Windows 原生窗口命中和实际屏幕，不能只证明 CDP 能操作页面。

课程按11章提供50个小步骤，依次介绍通用设置、剪贴板、便签、截图取色、文件、图片视频、录屏、识别提供商、翻译参数、网页快开、文件搜索和快捷键，不教学系统指令。引导按 Windows 发行版展示快捷键。复制练习提供可选取正文，用户亲手选中并用 Ctrl+C 复制，再长按配置的中键呼出面板，切回固定列表并选择剪贴板。继续练习选中、搜索、右键收藏、填写备注、收藏分类和悬浮；便签继续练习编辑、打开外观菜单、纸色、透明度、新建、贴边收起和展开，不因只完成第一项就跳到下个工具。

系统桌面中排他创建 `TabDo入门练习-<本次UUID>/`，放入原创练习文本、图片、二维码和三秒样片。工具的文件选择默认目录临时定位到这里，下载、图片、视频与文档输出临时定位到其中的“练习输出”。修改仅作用于隔离实例的路径 API 和对话框，不更改系统桌面位置或正式资料。用户在真实对话框选择文件；引导不代替用户点击或选择。

每步先保存基线，再检测实际操作结果：真实复制序号递增、设置字段保存、列表选中和筛选、收藏备注持久化、同一便签窗口折叠与展开、原生截图取色确认、文件内容保留、媒体输出非空且稳定、识别产生新历史后再复制等。准备参数、观察结果和执行分别教学；稳定结果出现后自动进入下一步，旧结果、取消和初始页面不算完成。不存在“我已完成”捷径；无法操作时可以恢复当前窗口、打开相关设置、跳过本步或本章，完成和跳过分别统计。

同一工具的连续步骤复用当前前台会话，恢复按钮优先显示并聚焦现有窗口，不反复装配。切换步骤取消旧检查；启动、正文就绪和状态查询都有有界等待，重复操作合并，迟到结果不能推进或复活课程。提示卡在工具装载期间保留退出入口；真实选图和保存对话框打开期间覆盖层暂隐并暂停检测，选择或取消后恢复。原生选区可取消返回。用户跳过悬浮步骤后，可在便签章节显式恢复一个真实便签继续练习。

引导直接打开“通用设置 → 超级面板”“剪贴板快捷匹配”“快捷键 → 内置快捷键 → Esc”并强调实际控件；识别教学分别在“提供商 → OCR”开启两项教学接口，再操作工具；翻译教学定位“提供商 → 翻译 → 谷歌翻译 → 服务配置”，实际修改目标语言并保存。设置页的页签深链在已打开页面中也有效。练习实例独占鼠标触发时，正式实例临时暂停面板触发、快速匹配和面板外点击监听，仍持续采集剪贴板；练习实际退出后恢复当前配置。不会复制正式配置、密钥、历史和第三方插件，也不创建第二个托盘。

按用户要求，模型识别、翻译与 Everything 只在隔离引导中调用 `resources/usage-guide-demo.cjs` 后台教学脚本。欢迎页、设置与工具正文均标注“教学演示”。OCR、公式、翻译返回固定样例，不分析实际图片、不联网、不安装模型或填写凭据；开关和参数仍需用户实际操作保存。Everything 模拟同一查询协议，仅对本次练习目录有界枚举、分类、关键词、排序与分页，不扫描电脑或启动真实 Everything。正常运行不走模拟分支；脚本再次校验引导环境和目录所有权，每次请求独立运行，取消/超时/连接断开后关闭，结果只在工作进程退出后交付，不产生过程文件。

正式资料下的 `usage-guide/environment/` 只保存可重建素材，`usage-guide/runs/<UUID>/` 保存本次独立数据库、Chromium资料与桌面位置清单。退出或宿主关闭后，先收束工具并等进程结束，再按内部清单和桌面标记双重核验清理所属目录；拒绝链接和不匹配的位置，绝不递归清理整个桌面。异常遗留在下次启动或再次开始体验时重试，存活进程或无法核验的目录保留并提示。完成后从关于选择保留或删除素材，保留不驻留后台，每次重进使用新副本。

练习使用真实工具界面和文件操作；教学接口的完成仅代表操作练习完成。复制会使用系统剪贴板，正式实例继续正常采集；截图录屏使用实际画面与所选音频；网页访问和识图可能联网。主动另存到专属目录外的文件及用户打开的外部程序由用户保留。正式使用时模型、账号和 Everything 仍需按实际能力要求准备，教学接口不会写入正式配置或替代正式服务。

宿主入口为 `usageGuide.ts`，桌面所有权与恢复为 `usageGuideFiles.ts`，覆盖窗口为 `usageGuideWalkthrough.ts`，纯判定规则为 `usageGuideVerification.ts`，步骤定义为 `src/shared/usageGuideSteps.ts`。测试通过 `pnpm test` 和 `pnpm test:e2e tests/e2e/usage-guide.spec.ts` 自动归档；E2E直接加载源码并使用隔离桌面、数据与旧资料目录，不为E2E打包。

免安装与安装包统一将全部 `resources/**` 物理展开；引导页面、样式、界面脚本与preload必须位于同一物理目录。窗口在收到界面首帧回执前保持隐藏；缺页、预加载错误、界面脚本未就绪或渲染进程退出时立即释放，10秒无回执也退出并提示，避免透明窗口阻塞桌面。提示卡获焦时可用Esc退出引导；工具或原生对话框获焦时，Esc遵循当前工具的关闭或取消行为。`usage-guide-startup.spec.ts` 使用源码Electron入口探测正常及失败边界，可通过 `TABDO_TEST_GUIDE_RESOURCE_ROOT` 直接读取已同步免安装资源进行同一加载路径验证，不启动成品主程序或改动预览资料。
