# 呼叫AI开发与使用规范

呼叫AI是 Windows x64 内置子组件，功能码为 `call-ai`。普通指令只打开一次性对话，不读取剪贴板。文本、图片和文件匹配带入所选资料，窗口匹配带入该窗口路径。匹配图片在发送前可移除，单张最多 4 MB，需使用支持图片输入的模型。

输入框工具栏提供附件、引用、结果目录和发送图标。通过回形针图标或拖放可添加本地文件，每轮最多 12 个。一般文件提供路径供本轮工具按需读取。声明支持图片输入的模型可直接接收 PNG、JPEG、WebP 和 GIF，单图最多 4 MiB，同轮最多 8 MiB。超出图片限制或模型不支持时仍提供路径。历史上下文仅保留最近一轮图片的字节。

## 框架与提供商

使用 [pi agent core](https://github.com/badlogic/pi-mono/tree/main/packages/agent) 1.5.0 的工具循环，构建时只打入实际使用的循环、参数校验和事件流，载荷约74KB；未使用的pi提供商不随程序打包。模型通过 TabDo 现有提供商适配器调用 OpenAI Chat、Responses 或 Anthropic。没有独立密钥表单、会话历史、跨对话记忆或进化功能。当前窗口中的多轮上下文只在内存中存在。

内置 [context-mode](https://github.com/mksglu/context-mode) 2.1.6，默认提供 `ctx_execute`、`ctx_batch`、`ctx_index`、`ctx_search`、`ctx_stats`。大段输出与文件优先使用这些工具。它作为独立本机 MCP 进程运行，工作目录、索引目录、HOME 和临时目录均指向本次会话，不接入宿主 Codex 索引；不暴露 resume、upgrade、purge 或代理配置改写工具。其他用户配置的 MCP 与 Skill 只在输入 `/` 选择后加载，下一轮需再次选择。

## 权限与退出

首次打开使用“请求批准”。确认过的权限模式保存在本机，新窗口恢复上次选择。启用“完全权限”须通过原生确认，输入框以红色盾牌提示该模式。获准代码和完全权限代码以当前用户身份访问文件与网络。

“请求批准”模式下，文件、代码执行、安装及 MCP 操作先展示完整参数。“批准本次操作”只批准当前操作。内置脚本及 context-mode 命令的卡片提供“允许类似命令”，在当前窗口内复用相同执行工具和完整参数的批准。脚本、解释器、路径或其他参数改变时重新审批，关闭窗口即撤销这类批准。基本执行边界包括独立工作目录、最小环境、IPC 身份校验、路径链接防护、输出上限、超时及 Windows Job Object 进程所有权。

命令在挂起状态下先加入 Job 再恢复执行，不允许 breakaway，根命令结束、取消、超时、窗口关闭或宿主退出均回收所属后代。独立编译器由 Windows .NET Framework 提供，准备失败时拒绝执行，不降级为无进程所有权的执行方式。会话有界命令超时120秒，模型单轮请求有界，用户回应等待最多5分钟。

聊天在独立窗口中打开，隐藏、最小化或失焦时保留会话。关闭窗口即撤销本会话能力，中止模型、未回应请求、命令及 MCP，销毁内存聊天和临时目录。用户自行打开的外部程序、配置、已安装插件及宿主全局剪贴板不属于清理范围。

## 运行时与设置

聊天输入框工具栏集中模型、权限、附件和网页搜索。模型选择器收起时显示模型名，展开后显示提供商、完整模型名和已配置的说明。权限收起时以盾牌图标区分模式，展开显示文字。地球图标切换网页搜索，高亮表示已开启。

设置侧栏的“呼叫AI”提供独立的 Skill 和 MCP 管理列表，条目可展开并单独启停。展开 Skill 可查看 `SKILL.md` 声明的描述。展开已配置的 MCP 后，点击“查看工具”临时连接服务，显示工具名称和说明，完成后释放连接。全局规则和运行时默认折叠。规则和手填路径在编辑结束后保存，目录选择和列表操作确认后立即生效。首次分离窗口为 650 × 440 的正文尺寸，缩放后的尺寸按呼叫AI单独保存。

Node 24 LTS 和 Python 3.13 嵌入版由 `pnpm build:call-ai` 从官方站点准备到忽略提交的 `resources/call-ai-runtime/win32-x64/`，随本地程序分发。运行时清单记录具体版本和来源。Python 标准库、pip、npm 与 context-mode 为预置能力；对话新增包只写入 `userData/call-ai/packages/{node,python}/`，关闭时保留，设置中可确认清理。npm 禁止安装脚本，包输入只接受包名和版本。更新使用专用暂存目录，失败恢复旧版本，不修改系统 Node/Python。“运行时与额外库”用图标提供更新和清理，悬停可查看操作名称。检查完成后，按钮旁显示绿色勾，行末显示“状态已检查”。

Skill 从含一个 SKILL.md 的 ZIP 安装，支持压缩包根目录或嵌套目录，保留说明所在目录的相对资源。最多 1000 项，压缩及解包大小各限 10MB，SKILL.md 最多 100KB。安装过程仅提取和登记，已有文件夹安装继续可用。对话可通过审批工具从本地 ZIP 或 HTTPS 链接安装。

MCP 支持 stdio 和 Streamable HTTP。可粘贴含 `mcpServers` 的 JSON，或通过“安装 npm 包”登记 Node 入口。stdio 可使用内置 `node`、`python`、`npx`，也可填写已安装服务的绝对程序路径。HTTP 入口接受 HTTPS 或本机 HTTP。npm 安装禁用包脚本；环境变量在本机保存。对话可以请求安装 npm MCP 包、添加或编辑配置。审批后登记能力，对话中通过“/”引用时连接，外部 MCP 在本轮结束后释放。

## 结果产物

连续模型往返只产生思考时，聊天复用同一折叠条目。产生正文或展示产物后，后续思考另起一条。

对话中指定的结果位置优先；未指定时使用设置中的默认位置，为本次窗口创建独立子目录。临时脚本与 context-mode 索引始终在会话目录中，结果不能写入运行时目录。关闭窗口不删除产物。

新建文本优先用 `write_file` 或 `write_files`。批量工具一次预检并批准最多 50 项，批准卡片展示解析后的绝对路径，空内容创建 0 字节文件。桌面由系统已知目录解析，其他位置使用完整路径。写入采用主进程文件 API 与 UTF-8，遇到冲突保留既有文件并回收本批已创建文件。审批前无需启动终端探测路径，内置 context-mode 无法启动时文件工具仍可用。

成功写入的文件以文件名链接展示。单击用系统默认软件打开，点击旁边的小图标可在文件夹中选中文件，悬停提示为「在文件夹中显示」。脚本工具可用 `artifacts` 声明新建的结果文件，主进程在执行前预检路径，成功执行后仅登记实际存在的普通文件。文件链接仅在生成它的窗口内有效。

系统默认目录使用“文档/TabDo/Call_AI”。已有自定义路径继续使用，旧系统默认位置的产物保留在原目录。点击“一键清理”显示原生二次确认，列出当前保存的默认位置和目录数量，只删除由本工具登记的产物子目录。该目录中的其他文件、旧默认位置以及用户指定到其他位置的产物保留。活动对话存在时禁止清理或更新运行时。产物索引只保存目录路径，不保存对话正文。

## 公网网页

每次打开窗口时“网页搜索”默认关闭，两种权限模式都以发送时的开关状态为准。开启即授权本轮调用内置网页检索和抓取，免逐次批准。关闭时也禁用 context-mode 的 URL 索引和第三方 MCP 引用。第三方 MCP 可自行调用任意服务，引用前须开启网页搜索，连接及操作仍按当前权限模式处理。通用代码执行遵循“权限与退出”所述权限。

模型的提供商直连 `https://api.deepseek.com` 时，`web_search` 和 `web_fetch` 分别调用官方 Search 和 Fetch，复用当前提供商的 Bearer 密钥。Search 只请求搜索结果，返回链接、标题和摘要，Fetch 单独读取 Markdown 正文。接口响应或模型工具参数格式错误时，模型收到可用于调整后续操作的工具错误。兼容网关按通用路径处理。参见 [DeepSeek 网页搜索与抓取](https://api-docs.deepseek.com/zh-cn/guides/search/)。

通用 `web_fetch` 读取公网 HTTPS 的 HTML 与纯文本，绑定连接使用的公网 IPv4 DNS 并逐跳检查重定向。通用检索需在“呼叫AI → 网页搜索”配置 Brave Search 密钥，由 Windows 加密存储。启用 JSON 接口的自建 SearXNG 可通过手动引用的 MCP 接入。网页正文作为任务资料。参见 [Brave Search API](https://api-dashboard.search.brave.com/api-reference/web/search/get) 和 [SearXNG 搜索接口](https://docs.searxng.org/dev/search_api.html)。

DeepSeek 和 Brave 使用代码登记的固定 HTTPS 端点。新增内置网页 API 时，在 `callAiWeb.ts` 的固定端点表登记官方地址，通过同一入口发送凭据。搜索词和待抓取地址仅作为查询参数或正文。共用入口使用系统 DNS 以兼容代理虚拟 IP，验证服务证书、拒绝重定向并限制响应大小。新增提供商的回归应覆盖虚拟 IP、拒绝重定向、凭据只发给登记端点，以及同一会话内重新开启网页搜索。
