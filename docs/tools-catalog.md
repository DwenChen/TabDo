# 工具指令与图标清单

演示编辑器的“缩放”检查器已升级为“变焦”，提供1–5×连续倍率及2D/3D镜头、角度预设、焦距、光圈、景深、对焦点和屏幕反光；继续使用原演示编辑器指令与变焦轨道，不新增重复工具入口。操作与兼容细则见[变焦镜头](presentation-zoom-camera.md)。

3D镜头保留运镜需要的画外录屏内容，深度放大时不因局部画幅旋转额外露底；真实录屏边缘进入取景时才显示原背景。

变焦片段名称区分2D/3D并显示倍率，悬停说明取景、有效光学参数和时间；光圈仅在景深开启后显示。选中注释和变焦自动定位有效时间，时间尺保留当前编辑上下文。摄像头删空撤下轨道并清空当前素材显示，保留磁盘原件及撤销恢复，重置不恢复旧虚拟音频条。

本文对应当前内置工具清单，以 `internal-plugins/system/public/plugin.json` 为准：共 40 个功能码、15 个分类、31 个普通文字指令。每个功能最多保留一个中文普通入口，其余入口按文本、图片、文件或窗口匹配。

同一功能可以包含不同输入规则。例如扫码分别接收图片内容和图片文件；悬浮中转接收文本、图片和任意文件，悬浮图片保留独立的图片匹配。普通入口数量不等于功能码数量，也不包含类型匹配规则。

剪贴板上栏在搜索框右侧留有拖动区域。截图和仅含图片的文件记录可一起多选，批量复制或拖出时保留各自的文件路径。

呼叫AI支持文字、图片、文件和窗口匹配。剪贴板图片以本次对话的临时文件加入待发送附件，悬停显示完整路径。聊天支持公式、代码复制、静态 HTML 和正文内 SVG 图示，图示可导出 SVG。

文件搜索结果可右键打开、定位、复制或复制路径，也可拖到资源管理器的目标文件夹复制。多选后从已勾选的条目拖动会带上全部勾选结果。底部的批量复制图标把选中的文件一次写入系统剪贴板。

“设置 → 所有指令 → 工具”的功能与匹配页都按清单的 `group` 归类，可搜索分类名；详情页使用同一分组函数。分类只改变展示，成员指令保留原功能码、匹配约束和菜单身份，打开、快捷键、固定、别名及禁用继续作用于该条指令。旧配置、固定项和已安装插件不做批量重写或清空，保留原功能码以支持旧入口。

## 重命名

编号与插入序号共用标签在左、数值在右的参数行，箭头列与字体一致；错误及移除图标采用居中的SVG。参数区不再套双层边框，插入页保留清楚的控件行距。

重命名的六个顶层标签分别应用当前功能，切换时不叠加其他标签规则。“规则清理”保留大小写、文件名清洗和扩展名三组勾选叠加；手动页提供多行输入和粘贴，点击“应用到预览”后核对。列表重算及刷新保留滚动位置；底部垃圾桶仅清空待处理列表，不删除文件。

## 演示录屏

“演示录屏”指令直接显示浮动录制控制条，点击“选择录制来源”弹出屏幕与应用窗口缩略图列表，选中后在目标边缘播放绿色流动高亮，中心透明。控制条使用演示录屏任务栏图标、六点手柄及简洁麦克风。控制条的“演示编辑器”入口打开编辑页；项目、最近项目与导入入口集中在编辑页。编辑页的“开始录制”返回控制条，停止录制后进入编辑器，可编辑光标、缩放、背景、标注与片段；项目和改动始终自动保存，工具栏保留撤销、重做、“导入项目”和导出。编辑区移除重复设置齿轮，设置集中在项目主页且无多余权限分类，致谢位于应用“设置 → 关于”。单个 `.recordly` 文件匹配“演示编辑器”。原有“录屏”仍用于快速捕获。项目引用原素材路径，移动时保留素材。

演示时间轴的文字、图片、箭头、模糊、聚焦及按键图标复用随包Solar细线图标，马赛克使用原创细线网格；片段图标随注释类型更新。录屏与其他轨道的移动关系见[时间轴关联规则](presentation-timeline.md)。

预览音量旁提供全屏播放与底部进度定位，嵌套页面失败时回退所属窗口原生全屏，局部提示不影响项目打开；编辑鼠标与录制光标独立可见，按键关闭图标斜线与其他关闭状态一致。实体键帽通过统一大小控件缩放，配色复用注释菜单；按键分组最大间隔按相邻按下时间差判断，变焦衔接最大间隔按两段之间空白判断，均包含等号边界。注释支持圆形及手绘遮罩、六款白底黑边卡通 SVG 箭头与默认关闭的进出场动画；不新增重复指令或独立窗口。操作细则见[预览、按键与注释](presentation-visual-effects.md)。

来源菜单按屏幕和应用窗口分组，选中后收起；再次点击、Esc或失焦可取消并保留此前来源。摄像头关闭以斜线图标表示。新增缩放默认1.5×，自动识别点击、有效停留及连续移动焦点；裁剪和变速按剪辑时间轴映射，已有片段保留，静止画面不强制缩放。关闭“自动为新录制应用变焦”后仍可主动点击“自动添加变焦”。摄像头画面可在预览中直接拖放，侧栏通过比例锁定和宽高调整大小；圆角默认100%，圆角、阴影及当前摄像头视频文件位于普通选项，高级仅保留缩放联动、镜像及素材区域裁剪。缩放“通用设置”默认收起，展开后可调整默认开启的连接变焦和默认平滑的“运动效果”（平滑/专注）。自动应用开关位于主页设置的通用分类。高级标题位于普通设置下方，重置位于右上角；场景提供独立背景/录屏圆角，紧凑裁剪支持八向手柄、选区移动、重新框选和比例选择。系统音频及麦克风首次加载即为独立音轨，名称位于左侧轨道栏，点击打开音频检查器。编辑窗口随工作区适配并保留时间轴，空时间轴支持点击加号或拖入视频。

仅保留中文。外观跟随 TabDo，编辑动作在“快捷键 → 内置快捷键 → 演示编辑器”管理，初始关闭；没有上游更新、账户、反馈、Discord 或插件入口。循环光标在片段末尾将轨迹平滑移回起点，方便循环播放，不操作系统鼠标。编辑器以独立窗口打开，最小化或失焦时保留会话，关闭时回收。来源、AGPLv3 与构建入口见 [组件说明](../internal-plugins/system/presentation/README.md)。

## 任务栏与生命周期

嵌入主窗口的可见工具进入正文时，更新窗口标题、原生图标及任务栏身份；返回搜索、切换、隐藏、终止或分离时，撤回宿主工具入口。分离和直接独立打开均使用当前子组件图标。便签保留专属原生图标并隐藏任务栏入口。悬浮中转、悬浮图片、图片标记、窗口信息与录屏控制条各自提供图标和任务栏入口。选区、倒计时、录屏输入效果和网页二级菜单属于临时覆盖层，不单独占据任务栏。

任务栏身份不决定会话是否保留。工具和插件默认退出即清理，已登记必要任务完成后销毁旧页面；TabDo 设置、演示编辑器、呼叫AI聊天及用户开启临时常驻的会话在隐藏或最小化后保留。便签、悬浮图片和中转内容窗口隐藏、最小化或关闭后销毁。全局剪贴板采集和持久资料不属于会话清理范围。

## 悬浮中转与临时常驻

悬浮中转是临时剪贴板小窗口，只接收明确转入的内容和窗口打开后的新复制，不导入全部历史，也不提供分类。入口位于剪贴板条目及右侧“复制并粘贴”按钮下方；多选时显示数量和转交状态。

| 操作       | 当前行为                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------- |
| 选择       | 左侧整列勾选，支持 Ctrl 切换、Shift 范围选择；Ctrl+A 再按一次取消全选                             |
| 复制与拖出 | 按显示顺序处理同类型条目；混合文本、图片、文件时禁止合并，正文拖出用于粘贴                        |
| 排序       | 新旧排序控制追加位置；删除按钮左侧手柄、Alt 拖动正文、上移/下移按钮可手动排序，之后新复制追加末尾 |
| 图片预览   | 列表显示小缩略图，点击放大；“悬浮固定”和“标记图片”仍使用各自独立窗口                              |
| 删除与清空 | 释放中转条目及所属临时图片，保留历史和原文件；关闭后新开为空窗口                                  |
| 反馈       | 结果提示约 3 秒、禁止提示约 4 秒后自动消失，重复触发重新计时                                      |

`floating-relay` 承接原“悬浮文字”功能；`float-content` 继续匹配图片和图片文件。便签用于独立编辑，右上角提供撤销、重做，正文右键保留剪切、复制、粘贴。

临时常驻属于工具或插件会话的宿主能力，开关固定在标题栏右上角，开发者只声明支持。用户启用时先分离，取消时立即关闭该独立会话；状态不写入配置。它与悬浮中转、便签的内容窗口是不同机制，详见 [插件规范](plugin-development.md#用户临时常驻)。

## 验证

通过 `pnpm test:regressions tools-catalog --list`、`pnpm test:regressions floating-relay --list` 查看覆盖范围。源码 E2E 从真实宿主进入，核对功能身份、匹配、禁用、旧页面释放、分离窗口和原生图标；中转专项另验勾选、排序、限时反馈与实际系统拖放。录屏专项检查控制条及实际视频结果。

列入测试清单不等于本轮通过。执行结果见 [维护记录](generated/CHANGES.md)，跨 DPI、多屏、任务栏合并策略和最终观感单独验收。

演示录屏始终录制鼠标；按需开启“录制按键”、系统音频、麦克风和摄像头。停止后按键自动载入轨道，在“按键”侧栏通过“显示按键输入”开关控制显示，并在下方调整外观；关闭显示保留已编辑内容，右上角“重置”恢复默认外观和显示。系统音频、麦克风和摄像头素材自动进入独立轨道，名称固定在左侧；点击声音调整音量、响度及淡入淡出滑条，素材起点随片段裁切和分割自动确定；摄像头画中画仍在侧栏设置。先选中片段定位到起点，再用时间尺设置切点；剪刀只分割该片段；切口紧邻且无竖条。各类片段右键菜单均提供“复制”“粘贴”和“删除片段”，也可在游标处分割；声音另可静音或恢复音量。复制保留素材偏移和外观，粘贴到游标处；单轨空间不足时寻找后方完整空隙，多轨自动避开重叠。拖动片段可调整同轨顺序，拖动左侧轨道名称可调整整轨排列，顺序随项目保存。拖动时显示落点提示，名称旁不显示手柄。缩放与横向浏览及时更新视频帧图，录屏和摄像头选区显示明显轮廓；点击固定刻度或片段外留白可定位游标。音频悬停显示名称、起止时间和时长。底部比例滑杆与加减按钮调整展示尺度，“适应全部”恢复全览；滚轮上下浏览，Shift＋滚轮或横向滚动条左右浏览，Ctrl＋滚轮调整比例。编辑片段时保留已选比例，刻度与显示到毫秒的游标时间在纵向滚动时固定。注释可拖动方框上方的圆形手柄旋转，按住Shift以15°对齐，也可在侧栏调整角度；箭头方向由旋转控制。所有类型片段选中后暂停定位到起点；移动注释后预览定位到片段内，移动、旋转及片段粘贴删除均支持撤销和重做。摄像头素材在侧栏替换，删除区间使用片段右键菜单。注释的模糊和马赛克相邻，只有聚焦、模糊、图片和马赛克提供圆角调节。

鼠标始终录制，按键默认关闭，按键选择仅保留在当前控制条会话；停止即移除采集监听，关闭会话恢复默认；记录物理按键与快捷键，不读取输入法提交文本。按键轨道在成片中叠加，原录制素材不被改写。

原始录制页的删除会将选中的库内素材及其专属伴随文件移入系统回收站，外部导入原文件不变；旧版本仅隐藏但仍在磁盘上的素材重新列出，可按新行为删除。项目删除前停止当前项目的待保存写入并卸载素材，防止自动保存重新生成项目。摄像头以补齐时长的WebM独立保存，不替换当前录屏、项目或光标轨迹；Windows屏幕和应用窗口统一使用WGC原生捕获，并明确禁止将系统指针写入画面，摄像头、屏幕及两路音频在同一操作边界启动、暂停、恢复和停止。

Windows 原始素材回收不请求提权，失败保留原件并显示系统原因；项目保存目录可在项目主页的“设置 → 文件”更改，新目录仅用于后续新建项目。

系统音频关闭斜线与麦克风统一为左上至右下。Windows演示录制使用明确排除系统指针的原生捕获，原生编码器、相机和麦克风并行准备后提交共同起止及暂停边界；画面、音频包、相机帧和键鼠依各自实际采集时间映射到同一时钟，不以文件长度差推测内容偏移。Windows相机使用MediaFrameReader的SystemRelativeTime，画面和相机共用QPC时间轴及60Hz输出；原生帧入队后独立编码，避免首包和编码回调阻塞造成首段错位；原始视频未二次编码。源目录回收被Windows安全检查拒绝时，通过用户临时目录的新副本回收，确认成功后才清理原件。
