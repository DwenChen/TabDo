# 项目结构与裁剪边界

本地版第一版为 `1.0.0`，基于上游提交 `6c9dee8`。

| 目录                            | 职责                                                     |
| ------------------------------- | -------------------------------------------------------- |
| `src/main`                      | Electron 主进程、插件运行时、超级面板、数据库、系统能力  |
| `src/renderer`                  | 插件宿主栏、超级面板及独立窗口界面                       |
| `src/preload`                   | 主界面的受控 IPC 桥接                                    |
| `resources/preload.js`          | 插件 SDK 兼容桥接，供既有插件复用                        |
| `resources/lib`                 | 随上游复用的预编译原生模块                               |
| `internal-plugins/setting`      | 独立 Vue 设置插件                                        |
| `internal-plugins/system`       | 保留的系统工具插件                                       |
| `resources/backup-worker.cjs`   | 应用退出后的归档、完整性验证、事务恢复与重启             |
| `scripts/preview-*`             | 无打包、无输出构建目录的本地源码预览                     |
| `tests`                         | 数据归档、插件、模型协议、系统能力及 Electron 端到端测试 |
| `.github/workflows/release.yml` | Windows x64 云端构建及 Release                           |

## 保留的能力

超级面板保留鼠标触发、长按配置、屏蔽应用、固定指令及排序、文本/正则/图片/文件/窗口匹配、插件与系统应用启动、翻译和 OCR 提供商。原主搜索窗口与超级面板共用的指令扫描、匹配、启动模块继续保留，超级面板仍在后台通过宿主完成匹配。

插件子输入框属于插件 SDK，继续供设置页筛选和第三方插件使用。主搜索框、聚合/列表搜索界面、搜索专属行为和悬浮球不再存在。唤起快捷键和托盘入口打开设置或当前插件。

## 移除的模块

账户注册/登录、OAuth、令牌刷新、云端同步与冲突管理、MCP 服务及配置页面、官方模型、官方活动心跳和支付窗口均已裁剪。插件市场以匿名方式浏览和安装，评论只读。插件 `getUser()` 返回 `null`；依赖官方身份、临时令牌或支付的功能不可用。

MCP 专属的工具注册桥接、悬浮球静态资源与 SDK 入口、主搜索界面状态和市场 Banner 资源一并删除。插件 provider 注册继续用于超级面板的翻译与 OCR。

数据库沿用上游 LMDB 文件格式与插件命名空间，以复用原模块和既有插件。`lmdb/syncApi.ts` 中的 Sync 指同步调用接口，并非联网同步服务。历史 `accounts/default` 目录保留作为本地唯一数据空间；不再支持账户切换。首次接管旧当前账户时保留原默认空间副本。

## 更新来源

版本查询直接访问 `api.github.com/repos/DwenChen/ZTools/releases`。下载、标准更新 Feed、关于页和问题反馈均指向本仓库。Windows 安装版复用标准更新器；便携版使用 Release 下载页完成更新。本版仅发布 Windows x64 产物。
