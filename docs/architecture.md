# TabDo 架构

TabDo 采用 Electron、Vue 3 和 TypeScript。主进程负责系统能力、数据与插件调度，渲染进程负责交互，重型模型和原生处理通过按次启动的工作进程执行。产品边界与版本策略见 [项目定位](project.md)。

## 模块职责

| 位置                             | 职责                                                 |
| -------------------------------- | ---------------------------------------------------- |
| `src/main`                       | 应用启动、窗口、超级面板、插件会话、数据库和系统服务 |
| `src/renderer`                   | 宿主栏、超级面板与独立窗口界面                       |
| `src/preload`                    | 宿主渲染器的受控 IPC 桥接                            |
| `src/shared`                     | 跨进程契约、默认值和纯逻辑                           |
| `resources/preload.js`           | 插件 SDK 与历史 API 兼容桥接                         |
| `resources/plugin-lifecycle.cjs` | 会话取消、清理器与有时限任务                         |
| `internal-plugins/setting`       | 通用、快捷键、插件、提供商及数据管理界面             |
| `internal-plugins/system`        | 内置工具页面、功能清单、图标与受控桥接               |
| `resources/*worker.cjs`          | 截图、识别、媒体、录屏、备份及目录迁移工作进程       |
| `resources/lib`                  | 保留来源说明和许可的预编译原生组件                   |
| `scripts/preview-*`              | 直接加载源码的开发预览与 Electron 测试入口           |
| `tests`                          | 单元、脚本、源码 Electron E2E 和历史回归分组         |
| `.github/workflows/release.yml`  | Windows x64 云端验证、构建与发布                     |

## 交互与调用链

超级面板接收配置的鼠标触发，读取当前选区或有效时限内的最近复制内容，经指令匹配选择内置工具、插件或系统操作。固定项保留用户排序；匹配项结合最近使用和频次排序。宿主复用后台指令扫描与启动能力，插件子输入框继续用于页面筛选。

渲染器经 preload 调用受控 IPC。宿主校验调用者身份、参数和会话状态后分派操作；原生处理结果只返回所属请求。窗口退出、请求替换或取消后，迟到结果不得更新新会话、抢焦点或重新显示窗口。

## 会话与任务

内置工具和第三方插件均采用会话所有权。隐藏、最小化、关闭或切换时立即取消前台活动，并从显示树和缓存移除旧视图；没有必要任务时销毁旧 WebContents。同一工具插件中的不同子组件也必须创建独立会话。

用户确认的保存、导出、文件事务和编码可在退出前登记为有时限任务。任务持有完整的计算、写入、发布、回滚及清理链，完成、失败或超时后释放资源。旧任务以原 WebContents 身份收尾，不得影响随后打开的会话。

隐藏 Provider 页面以引用计数合并并发装载，最后一次调用结束后回收。用户主动创建的可见便签、悬浮图片和录屏控制条具有独立会话；窗口隐藏、最小化或关闭即执行各自的退出流程。全局剪贴板采集属于宿主，不随工具页面退出停止。

## 数据与兼容

配置、插件文档和附件使用本机数据根目录，默认位于 `~/.tabdo`。数据库沿用 LMDB 文件格式与历史命名空间，`setting`、`system` 标识保持稳定；`accounts/default` 是历史格式中的本地数据空间，不提供账号切换。`lmdb/syncApi.ts` 表示同步调用接口。

备份、恢复和根目录迁移均在应用完全退出后执行，逐文件校验后发布，保留原数据或回滚副本。路径失效时明确报错，不能回退为空白资料。具体范围见 [数据文档](backup-and-migration.md)。

## 网络与产品边界

应用更新来自 `DwenChen/TabDo` Releases，插件索引来自独立的 `DwenChen/TabDo-plugins`。在线翻译、AI、网页搜索和图片搜索由用户选择服务；离线模型首次启用时下载并校验资源。配置密钥与用户数据不进入源码仓库。

TabDo 不提供上游账号、云同步、支付、官方模型服务或 MCP 服务；`getUser()` 为历史兼容接口并返回 `null`。旧 SDK 别名和类型资料仅用于迁移，不代表旧市场或旧服务可用。当前发布范围为 Windows x64，保留的其他平台代码须经独立验证后才能形成正式支持承诺。
