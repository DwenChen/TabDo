# 数据备份与迁移

在设置中打开「数据备份与迁移」。选择导出文件后，应用退出，后台工作进程在原进程完全结束后创建 `.ztbackup` 文件，完成后自动重启。再次打开本页面可查看结果。

## 备份内容

备份覆盖完整数据根目录：设置和配置、模型提供商与密钥、LMDB 文档及附件、已安装插件文件、`plugins-data`、剪贴板文件、浏览器分区的本地存储与会话，以及扩展资源。配置在根目录外的插件也会收录，恢复后放入 `plugins/migrated-*`，并重定位宿主保存的插件路径。

临时文件、运行日志、标准浏览器缓存和进程锁排除。归档含版本、平台、原路径、完整文件清单和逐文件 SHA-256。当前归档实现的总解压数据上限为 20 GiB，适合本地工具配置与插件迁移；大文件备份需要足够内存和磁盘空间。

备份没有加密，包含 API 密钥、插件私有数据及会话。请在可信位置保存。浏览器与系统绑定的受保护凭据可能需要在目标电脑重新登录，插件私有文档中的外部文件引用也需要由插件自行调整。外部应用程序、用户文件及本地启动项指向的任意目标不属于插件安装文件，不会连带复制。

## 恢复与回滚

1. 选择备份并在原生确认窗口中确认恢复。
2. 应用退出，工作进程将文件解压到数据目录旁的新暂存目录。
3. 校验归档版本、路径、重复条目、文件大小、文件清单及 SHA-256，全部通过后才替换数据。
4. 原数据目录重命名为 `.ztools.rollback-时间戳`，再发布新目录。发布失败时恢复旧目录。
5. 重启后重定位宿主配置中的数据根目录与插件路径。

校验失败时保留现有数据；结果记录在数据根目录的 `.backup-result.json`，打开备份页后展示。需要手动回滚时，先退出所有 ZTools 进程，将当前数据目录移开，再将回滚副本改回原目录名。

迁移优先在同一操作系统和架构之间执行。跨系统后检查外部路径、快捷键以及包含原生模块的插件，必要时重新安装插件。为避免归档越过数据边界，目前遇到符号链接会明确拒绝导出。

## 路径

- 正常运行：用户主目录下的 `.ztools`。
- 源码预览：仓库的 `.local/source-preview-data`，不使用正常运行目录。
- 测试：操作系统临时目录中的独立目录。
- `ZTOOLS_DATA_ROOT`：显式指定其他数据根目录。

沿用旧数据库目录名仅为文件兼容；本版没有联网账户或同步服务。
