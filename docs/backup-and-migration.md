# 数据备份、恢复与迁移

在设置的数据页面选择导出位置。应用退出后，工作进程等待原进程完全结束，再创建 `.ztbackup` 文件并重启应用；重新打开页面查看结果。备份、恢复和目录迁移都不能通过在线复制数据库完成。

## 备份内容

备份覆盖完整数据根目录：设置和配置、模型提供商与密钥、LMDB 文档及附件、已安装插件文件、`plugins-data`、剪贴板文件、浏览器分区的本地存储与会话，以及扩展资源。配置在根目录外的插件也会收录，恢复后放入 `plugins/migrated-*`，并重定位宿主保存的插件路径。

临时文件、运行日志、标准浏览器缓存和进程锁排除。归档含版本、平台、原路径、完整文件清单和逐文件 SHA-256。当前归档实现的总解压数据上限为 20 GiB，适合本地工具配置与插件迁移；大文件备份需要足够内存和磁盘空间。

备份没有加密，包含 API 密钥、插件私有数据及会话。请在可信位置保存。浏览器与系统绑定的受保护凭据可能需要在目标电脑重新登录，插件私有文档中的外部文件引用也需要由插件自行调整。外部应用程序、用户文件及本地启动项指向的任意目标不属于插件安装文件，不会连带复制。

## 恢复与回滚

1. 选择备份并在原生确认窗口中确认恢复。
2. 应用退出，工作进程将文件解压到数据目录旁的新暂存目录。
3. 校验归档版本、路径、重复条目、文件大小、文件清单及 SHA-256，全部通过后才替换数据。
4. 原数据目录重命名为 `.tabdo.rollback-时间戳`，再发布新目录。发布失败时恢复旧目录。
5. 重启后重定位宿主配置中的数据根目录与插件路径。

校验失败时保留现有数据；结果记录在数据根目录的 `.backup-result.json`，打开备份页后展示。需要手动回滚时，先退出所有 TabDo 进程，将当前数据目录移开，再将回滚副本改回原目录名。

迁移优先在同一操作系统和架构之间执行。跨系统后检查外部路径、快捷键以及包含原生模块的插件，必要时重新安装插件。为避免归档越过数据边界，目前遇到符号链接会明确拒绝导出。

## 路径

| 场景           | 资料位置                                                              |
| -------------- | --------------------------------------------------------------------- |
| 正常运行       | 默认用户主目录下的 `.tabdo`，可在通用设置中更改                       |
| 源码预览       | 仓库 `.local/source-preview-data/` 和 `.local/source-preview-legacy/` |
| 固定免安装预览 | 通过 `PreviewPortable.cmd` 指向 `.local/portable-preview/` 的隔离资料 |
| 自动化测试     | 用例显式设置的临时 data 与 legacy 目录                                |
| 自定义启动     | `TABDO_DATA_ROOT` 指定的数据根，按其位置记录继续解析                  |

免安装程序不会仅因 exe 位于某个目录，就自动将该目录用作数据根。更换程序目录时保留原数据位置、环境变量和启动参数。

## 更改数据与缓存目录

通用设置中的“数据与缓存目录”同时管理配置、已安装插件、剪贴板与浏览器会话/缓存，并非只清理临时文件。选择一个空文件夹并点击“迁移并重启”，原生确认后应用退出；`resources/data-location-worker.cjs` 等待原进程完全结束，再将整个数据根复制到目标旁的独立暂存目录，逐文件 SHA-256 校验，通过后发布目标并记录位置，随后重启。原目录完整保留，目标非空、相互嵌套、符号链接或复制校验失败均拒绝切换，不覆盖既有资料。

启动位置记录在初始根目录的 `.data-location.json`（普通运行即 `~/.tabdo/.data-location.json`）；`TABDO_DATA_ROOT` 和免安装预览均以各自的隔离目录作锚点。`userData`、`sessionData` 和插件分区统一使用新目录，宿主文档中的原根路径会重定位；根外开发插件与插件私有文档中的外部引用保持原位置。迁移结果写入当前根的 `.data-location-result.json`，重开设置可查看。

目标丢失或位置记录损坏时启动明确报错，禁止悄悄创建空白资料。人工恢复需先退出全部所属进程：恢复目标及位置记录，或在确认原件可用后移走锚点的 `.data-location.json`，使下一次启动恢复原根；不同阶段的 LMDB 不能直接合并。数据量和磁盘速度决定迁移耗时，多磁盘、权限及掉电恢复仍需真实设备验收。

沿用旧数据库目录名仅为文件兼容；本版没有联网账户或同步服务。
