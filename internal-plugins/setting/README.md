# TabDo 内置设置插件

本插件的稳定标识为 `setting`，使用 Vue 3 提供通用设置、快捷键、插件、提供商、AI、数据管理与本机服务配置。页面按需加载，切换时卸载旧页面并释放订阅。

## 开发

设置插件独立维护 package.json 和锁文件，首次准备时安装本目录依赖。通过仓库根目录 `pnpm preview:local` 与宿主共同运行，开发地址为 `127.0.0.1:15177`；单独打开页面不具备完整宿主桥接。

遵守 [设置开发规范](../../docs/settings-development.md)与[维护流程](../../docs/maintenance.md)。应用快捷键集中管理并默认关闭；初始化只补缺失配置，保留用户已保存的状态。

## 验证

执行根目录 `pnpm typecheck:setting` 及相关源码 Electron E2E。截图直接捕获设置插件的稳定正文，使用隔离数据，避免读写正常用户目录。

数据备份、恢复和目录迁移由宿主及退出后的工作进程完成，界面不直接复制数据库。流程见 [数据文档](../../docs/backup-and-migration.md)。
