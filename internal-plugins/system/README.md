# 工具

**开发必读：[工具子组件开发原则](../../docs/tools-development.md)。** 新增或修改子组件及相关宿主能力必须遵守资源归属、必要任务登记和退出清理要求。工具界面退出后立即释放，必要任务完成后释放；剪贴板全局采集与持久化记录继续保留。

工具默认嵌入主窗口，内置插件不提供右上角运行行为设置入口；专属会话释放与子进程清理各自负责页面和操作资源，退出机制详见开发原则。

内置截图、剪贴板、文字与公式识别及常用系统操作。文字识别保留坐标标注与图上选文，识别后的“翻译”按钮复用翻译提供商，将选文或全部英文结果译为简体中文。插件标识保留为 `system`，兼容已有快捷键和配置。提供商统一在设置页配置，详见 [内置提供商与工具](../../docs/builtin-providers.md)。

剪贴板界面基于 [ZToolsCenter/TabDo-plugins clipboard](https://github.com/ZToolsCenter/ZTools-plugins/tree/main/plugins/clipboard)，源码版本 `02cc9ea00801da59c492c509e6d78a347e7d9df0`，遵循 MIT 许可证（见 LICENSE.clipboard）。本地版增加代码和链接分类、代码高亮及查询时分类分页，移除多选复制的版本检测。

Windows 截图原生模块的可复现构建与变更说明见 `resources/lib/win/SCREENSHOT.md`。复制后中键匹配默认有效 5 秒，可在通用设置调整；0 表示关闭。

超级面板始终启用，新配置默认按下中键弹出，保留用户已有按键和长按时长。面板鼠标入口始终优先复制并匹配当前选中的文本或文件。中键单击没有取得选区内容时，再匹配有效时限内的最新复制；两者都没有则显示固定指令。面板改用其他按键时，独立的复制后中键入口只处理时限内的最新复制。窗口外点击同时取消未完成的复制请求，避免迟到结果重新弹窗。预览同步需要同时替换 `out`、`resources` 和内置插件构建产物，尤其包括插件使用的 `resources/preload.js`。

进入分类或刷新后不默认选中任何条目。勾选多个同类条目后，可使用侧栏复制按钮或 Ctrl/Cmd+C 合并复制；宿主搜索框没有选中文字时也会把复制快捷键转发到插件。

开发及 E2E 由 `scripts/preview-local.cjs` 自动启动源码服务器（15178），无需打包。预览同步时将本插件构建产物替换到程序资源，保留所有用户数据和外部插件。

新增工具入口：**文件重命名**、**解散文件夹**、**二维码扫描**、**图片标记**、**悬浮文本 / 悬浮图片**、**便签**、**本地文件搜索 / Everything**。文件、图片和文字选区均按各指令支持的匹配类型进入；扫码仅识别，不提供二维码生成。HTTP(S) 扫码结果由用户点击后交给系统默认浏览器，不自动打开任意协议。复制路径与复制名称由宿主完成并登记为剪贴板文本条目，从面板或快捷键触发时不闪出宿主窗口。

参考上游 [file-renamer](https://github.com/ZToolsCenter/ZTools-plugins/tree/main/plugins/file-renamer)、[qrcode-helper](https://github.com/ZToolsCenter/ZTools-plugins/tree/main/plugins/qrcode-helper)、[clipboard-image-paintbrush](https://github.com/ZToolsCenter/ZTools-plugins/tree/main/plugins/clipboard-image-paintbrush)、[sticky-note](https://github.com/ZToolsCenter/ZTools-plugins/tree/main/plugins/sticky-note)、[local-search-neo](https://github.com/ZToolsCenter/ZTools-plugins/tree/main/plugins/local-search-neo)，调研版本 `c8475ad7944ffdb78843cc5f56886d1443d0a724`。本地适配使用统一的 Vue 工具入口与独立资源作用域；不装载这些外部插件、不迁移或修改其私有数据。二维码解码使用 jsQR 1.4.0（MIT），原许可随源码保留在 `public/LICENSE.jsqr`。

重命名直接复用上游 [batch-rename](https://github.com/ZToolsCenter/ZTools-plugins/tree/main/plugins/batch-rename) 的编号卡片、替换/插入/手动/智能面板、图标及底部操作栏，适配提交 `af6dc6df9bae6dc61022dabeb3a1d0c54e6de8f2`，许可见 `public/LICENSE.batch-rename`。上栏顺序为自动编号、查找替换、规则清理、插入内容、手动编辑、智能重命名。规则清理使用四个紧凑分组：大小写转换、文件名清洗、扩展名处理、删除字符，参考 [file-renamer](https://github.com/ZToolsCenter/ZTools-plugins/tree/main/plugins/file-renamer)。原名和新名采用双列预览，手动页支持行内编辑与多行粘贴，非法名称直接标错；筛选和虚拟列表保持编辑位置。智能页进入时才读取模型列表。预览在可终止 Worker 中计算，执行前重新检查文件身份、名称和冲突。通过同目录临时名支持交换与大小写改名，失败执行两阶段回滚；恢复路径记录在工具私有数据 `rename-recovery`，成功后清除。本会话可撤销上次改名；不递归处理目录，不接受父子路径混合批次或符号链接。

解散文件夹参考 [dir-break](https://github.com/ZToolsCenter/ZTools-plugins/tree/main/plugins/dir-break)：把目标目录的内容移到父目录后删除空目录，支持单层与递归、自动重命名/覆盖/跳过三种冲突策略，执行前展示文件数、目录数、类型统计与结构变化；文件事务失败先回滚，最近 50 条记录保存在本插件命名空间并可撤销。

剪贴板的纯图片文件组显示在“图像”中，混合文件组保留在“文件”中；复制图片文件仍复制原文件载荷。图片与文本条目右键可“悬浮固定”，图片还可“标记图片”；文本条目右下角还可直接“悬浮固定”。文字默认以空行追加到最近聚焦的便签，保留当前编辑；多个窗口关闭后顺延，没有存活窗口才创建。独立“便签”指令、标题栏“＋”和 Ctrl+N 主动新建空白便签，新窗口错开位置。文字便签仅保留当前窗口编辑内容，关闭即结束，无历史入口。悬浮窗口由宿主独立持有，可在剪贴板退出后保持可见，隐藏、最小化或关闭立即销毁；便签复用原插件的窄彩色标题栏及五种纸色，并以透明折角形成纸张轮廓。图片窗口复用原插件暗色 SVG 工具栏，颜色圆圈点击展开基本配色，荧光笔独立记住颜色且不显示黑白；五档笔触大小点单独显示；支持画笔、荧光笔、橡皮擦、箭头、矩形、椭圆、文字、马赛克和撤销/重做。工具栏按分组响应换行，窗口初始贴合图片与工作区，图片可按原尺寸滚动查看。界面来源与许可见 [悬浮窗口界面来源](../../resources/tools-floating-ui.md)。

本地搜索独立实现 [Everything Unicode IPC query2](https://www.voidtools.com/support/everything/sdk/ipc/)，按 100 条分页，支持分类、排序、正则与大小写，并提供有界文本、图片、目录及音视频预览。查询桥接仅在本地搜索子组件中启动，退出或切换子组件后释放；不会启动、停止或修改用户 Everything。程序不携带 Everything.exe、SDK DLL、索引或个人配置。未安装、未启动、索引中和无响应分别提示；用户通过官方下载标准版，在“工具 → 选项 → 常规”开启开机自动运行，建议使用 Everything 服务。Lite 不支持 IPC；支持常见默认实例、1.5a 和自定义命名实例。

本地搜索界面复用 `691870b5b45a209f34b3626b162efeb00f177601` 的 `local-search-neo/src/Finder` 的分类侧栏、双行结果、预览和底栏结构及明暗样式，适配本地查询桥接与连接指引；MIT 许可随 `public/LICENSE.local-search-ui` 保留。文字/公式识别参考原 `f-provider` 的图片与结果双栏，窄窗口转为上下排列。公式使用 KaTeX 0.16.22 在本机生成受限数学预览（禁止受信任 HTML 扩展），支持源码、行内与独立公式复制。

多选文本点击任一已选条目的「悬浮固定」，会按当前列表顺序合并所有已选文本。便签全部关闭后，下一张恢复黄色「便签 1」；只有桌面仍有便签时，新建才递增编号并轮换颜色。拖动到工作区边缘后释放即收起为彩色编号标签，拖动中暂停不收起，悬停不展开；点击或拖离边缘解除贴靠，色签可以沿边缘自由移动。便签选项的贴靠开关控制本次运行的全部便签，关闭后恢复完整纸张；字号 12–32 像素只作用于当前窗口。普通图片悬浮隐藏标记工具栏，置顶、关闭保持淡显，进入后完整显示；画布铺满窗口，等比缩小与拖动保持最近缩放尺寸。

工具界面统一以剪贴板、OCR 为参考，复用系统字体与主题变量，默认绿色强调色并保留宿主主题注入。重命名沿用上游功能布局，文件名、输入框与控件改用统一系统字体，选中、勾选、焦点和执行按钮不再保留上游蓝色。具体字号、间距、主题和截图要求见开发原则。

二维码、解散文件夹不重复显示子组件标题与介绍。二维码始终左侧图片、右侧结果等宽分栏，图片保持比例并充分利用左栏，结果独立滚动；按宽度计算有界高度，使窗口尽量方正，窄窗改为上下分栏。解散文件夹将目录入口、模式及冲突策略收紧为两行。超级面板恢复最初 250×400 默认窗口，固定宽度 250，高度按正文在 250–400 DIP 内调整；匹配列表仅显示指令名称，候选中上次使用置首、其余按频次排列。头部可拖动，返回按钮等控件保持可点击。

工具之间直接切换时，宿主在占位/显示前将旧视图退出显示树和缓存，释放前台资源，必要任务结束后关闭旧 WebContents；不能以相同插件路径复用上一工具页面。重命名按钮为“执行重命名”，名称和目标冲突在预览中逐行提示，可刷新检查外部变化；执行仍重新校验并直接完成，不再二次确认，失败回滚和撤销保留。模型未配置等状态提示占据独立布局空间，使用不透明明暗主题背景。

文件搜索本轮重新对照上游提交 `691870b5b45a209f34b3626b162efeb00f177601`，使用原十类分类、可调整宽度的侧栏/列表、设置抽屉、自定义分类及排序底栏。搜索输入使用宿主顶部搜索框；无需关键词即可点击分类浏览文件。排序、预览、路径匹配、分类显隐/顺序和自定义规则在内置工具内独立保存。

**录屏**：移植指定 [screen-recorder](https://github.com/ZToolsCenter/ZTools-plugins/tree/af6dc6df9bae6dc61022dabeb3a1d0c54e6de8f2/plugins/screen-recorder) 的 Windows x64 原生录制引擎，界面适配统一 Vue 工具风格。支持全屏、窗口、区域，系统声音、麦克风、鼠标和倒计时，保存 MP4。开始后独立控制条显示用时，停止按钮或 F10 保存；关闭、隐藏或最小化控制条也会收尾。来源、许可及进程清理见 [录屏说明](../../resources/recorder/README.md)。系统和音频设备边界需人工验收。

**网页快开**：配置文本搜索网站（网址包含 `{query}`）和 Bing / Google Lens 识图引擎。匹配指令 **文本搜索** 和 **以图搜图** 自动接收选区或图片；启用多个网站/引擎时弹出二级选择菜单，单个直接使用。关键词编码进搜索地址，图片上传到所选引擎后，都在系统默认浏览器打开结果。Lens 通过一次性回环页面把内存图片交给默认浏览器直接上传，避免跨浏览器会话失效；页面领走即关闭服务，取消、失败或 60 秒超时同样清理。配置在工具自己的命名空间保存，不读取外部插件配置；不保存临时图片、不使用第三方图床。

**图片批量处理 / 视频批量处理**：按用户提供插件的左侧功能、中间参数、右侧队列三栏移植，统一系统字体、绿色强调色和明暗主题。支持转换、尺寸、裁剪、水印、旋转、合并等图片与视频操作及文件匹配；另有图片文件夹、手动裁剪和合并直达入口。独立进程处理，保留源文件，同名输出自动编号，可取消并等待清理。

录屏本轮对照用户提供的 2.1.0 更新六参数原生引擎、质量设置和输入效果，沿用来源/选项双栏与设置抽屉；新增区域录屏、停止录屏快捷指令。控制条为 12px 圆角矩形、透明四角，保留拖动和捕获排除。来源、功能边界和回归见 [媒体工具说明](../../docs/media-tools.md)。

录屏已按用户提供的 2.1.0 重做：全屏单列大预览、窗口图标列表、3–9 秒分段与中心倒计时；点击区域直接打开可调整选区，确认后才开始。原版式设置抽屉包括独立左右键颜色/Emoji、五种键帽和九宫格位置。自动保存至设置目录，停止封装完成后定位文件，圆角控制条及捕获排除继续保留。图片/视频默认输出各源文件同级目录，合并输出到首个源文件目录，剪贴板图片回退下载目录，可切换自定义目录。文件搜索移除命名实例输入，将正则/大小写放入有说明的搜索方式分组；旧实例配置保留兼容。

工具指令已按 13 类整理，37 个功能保留原功能码与输入匹配，普通文字指令只保留唯一中文名称。各功能采用独立 Lucide 图标，任务栏与分离窗口使用同一套本地 PNG；来源、完整清单和退出规则见 [工具指令与图标清单](../../docs/tools-catalog.md)。
