# TabDo 内置工具插件

本插件的稳定标识为 `system`，负责剪贴板、截图取色、识别、文件整理、便签、媒体及系统操作的工具入口。完整功能和图标以 [工具清单](../../docs/tools-catalog.md)及 `public/plugin.json` 为准。

## 开发入口

新增或修改子组件及相关宿主能力前，阅读 [工具开发规范](../../docs/tools-development.md)。源码页面位于 `src/components/`，共享主题和生命周期由插件入口提供；开发预览与源码 E2E 通过根目录的 `pnpm preview:local` 自动启动工具服务（15178）。

新增可见页面同时登记功能清单、Vue 路由、宿主工具视图白名单、首帧尺寸、原生图标和任务栏身份。验证必须经真实 `tabdo.launch` 入口进入。

## 运行与数据

工具默认嵌入宿主窗口。切换子组件、隐藏、最小化或关闭时释放旧页面的前台资源，已登记的必要任务完成后销毁旧 WebContents。独立可见便签、悬浮图片和录屏控制条持有自己的会话；隐藏或关闭按各自规则收尾。

配置、收藏、剪贴板历史和已安装插件属于持久资料，不进入会话清理范围。全局剪贴板采集由宿主持有。便签内容属于当前窗口，不提供持久化历史；相邻贴边色签按编号整理，仅调整窗口位置。

本地文件搜索使用自有 Everything IPC 桥接，退出时只释放桥接，不停止用户的 Everything，也不携带其索引或个人配置。配置自动识别常用实例，旧命名配置仅用于兼容。

交付时构建本插件并使用根预览同步脚本替换程序资源，对已有 data 和 legacy 逐文件核验；不能通过清空配置或插件获得可用预览。
