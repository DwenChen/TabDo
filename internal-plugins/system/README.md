# 工具

**开发必读：[工具子组件开发原则](../../docs/tools-development.md)。** 新增或修改子组件及相关宿主能力必须遵守资源归属、必要任务登记和退出清理要求。工具界面退出后立即释放，必要任务完成后释放；剪贴板全局采集与持久化记录继续保留。

内置截图、剪贴板及常用系统操作。插件标识保留为 `system`，兼容已有快捷键和配置。

剪贴板界面基于 [ZToolsCenter/ZTools-plugins clipboard](https://github.com/ZToolsCenter/ZTools-plugins/tree/main/plugins/clipboard)，源码版本 `02cc9ea00801da59c492c509e6d78a347e7d9df0`，遵循 MIT 许可证（见 LICENSE.clipboard）。本地版增加代码和链接分类、代码高亮及查询时分类分页，移除多选复制的版本检测。

Windows 截图原生模块的可复现构建与变更说明见 `resources/lib/win/SCREENSHOT.md`。复制后中键匹配默认有效 5 秒，可在通用设置调整；0 表示关闭。

已启用超级面板的鼠标入口始终优先复制并匹配当前选中的文本或文件。中键单击没有取得选区内容时，再匹配有效时限内的最新复制；两者都没有则显示固定指令。未启用超级面板时，独立的复制后中键入口只处理时限内的最新复制。窗口外点击同时取消未完成的复制请求，避免迟到结果重新弹窗。预览同步需要同时替换 `out`、`resources` 和内置插件构建产物，尤其包括插件使用的 `resources/preload.js`。

进入分类或刷新后不默认选中任何条目。勾选多个同类条目后，可使用侧栏复制按钮或 Ctrl/Cmd+C 合并复制；宿主搜索框没有选中文字时也会把复制快捷键转发到插件。

开发及 E2E 由 `scripts/preview-local.cjs` 自动启动源码服务器（15178），无需打包。预览同步时将本插件构建产物替换到程序资源，保留所有用户数据和外部插件。
