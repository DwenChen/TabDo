# 演示录屏与演示编辑器

录制库对根目录和选择路径的父目录统一解析真实位置，兼容Windows短路径与指向同一库的目录别名；移除、撤销和指定回收使用同一事务身份。已经移入暂存的素材不要求原文件仍存在，指向库外的目录别名继续拒绝。

麦克风菜单的电平检测仅在当前菜单会话持有设备，最多每秒分析20次；关闭、切换设备、权限迟到或音频准备失败均释放自己的流与上下文。导出顺序解码在取消时解除帧等待和背压，关闭迟到帧；已取消的媒体加载不得重新创建解码器或工作进程。后端清除已取消定时器的记录，退出时解除所属页面监听。标准及现代导出路径继续保留，已无调用方的旧 `VideoFileDecoder` 接口移除。

原“缩放”侧栏升级为“变焦”：1–5×连续倍率滑条，2D/3D镜头切换，拖动角度与六种预设，焦距、光圈、景深、对焦点和屏幕反光。旧六档项目继续保持原倍率及二维效果，参数随片段保存并支持撤销重做；预览与两套导出器共用透视和光学滤镜。详细操作、格式和渲染边界见[变焦镜头](../../../docs/presentation-zoom-camera.md)。

3D运镜从完整录屏平面取景，保留需要的画外内容；深度放大且镜头仍在录屏内部时保持铺满，真正看到录屏边缘时才自然露出原背景。预览、运动模糊与两套导出器遵循同一取样边界。

变焦片段精简显示2D/3D、倍率和自动/手动，悬停提供完整名称、有效光学参数与毫秒时间；开启景深后才显示光圈，关闭保留已设数值。所有类型片段选中后均暂停定位到起点，重复点击也生效，手动时间尺浏览保留选区和检查器。

录屏重排时，变焦、普通注释与按键注释只随实际覆盖画面移动，分离部分拆段；字幕和鼠标按源时间投影，独立声音及摄像头保持自己的时间位置。渲染不拉长短片段或重排声音。新增注释共用空闲导轨分配并自动滚入视口，片段图标随注释类型更新。完整边界见[时间轴关联规则](../../../docs/presentation-timeline.md)。

摄像头最后一段删除后，撤下空轨并解除当前项目素材引用，侧栏只保留导入入口且重置禁用；原文件保留，撤销恢复全部状态，重新导入重新建立片段。分类重置不能复用旧格式迁移而生成虚拟音频条；已独立编辑的来源不再显示旧虚拟条，系统音频和麦克风继续使用可删除的独立片段。

基于 [Recordly](https://github.com/webadderallorg/Recordly/tree/109ca3a13c362e969d9add25d1f93406c36dba2a)，固定提交 `109ca3a13c362e969d9add25d1f93406c36dba2a`，上游 package 版本 1.4.0。研究与修改日期：2026-10-27。原作者 webadderall；源自 Siddharth Vaddem 的 OpenScreen。完整许可见 [LICENSE.md](LICENSE.md)，依赖许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

本目录保留上游编辑器、录制与项目格式的来源；`tabdo-*` 文件及宿主服务负责适配。没有执行上游 main、更新器、独立托盘或账户服务。中文为唯一语言；主题由 TabDo 注入，六项编辑动作在设置的快捷键页管理，初始关闭。原有“录屏”功能及其配置保持独立。

工具入口为 `presentation-recorder`，直接显示浮动录制控制条；通过控制条的“演示编辑器”进入编辑页，项目、最近项目和导入入口集中在该页。编辑页“开始录制”返回控制条，停止后进入编辑。单个 `.recordly` 文件匹配 `presentation-editor`。项目文件保持上游格式，引用视频、声音等原始素材；转移项目时也要保留引用的素材。所有项目（含未命名项目）及编辑改动自动保存，工具栏提供撤销、重做、“导入项目”和导出。循环光标使末尾的光标动画回到起点，便于循环观看，不移动系统鼠标。

宿主先把视图分离，再按 WebContents 创建独立模块闭包和带前缀的 IPC；控制条获取焦点不再触发主搜索窗口的失焦清理。控制条可见时隐藏编辑宿主并卸载编辑正文，全部所属窗口退出前台后按普通生命周期回收，不自动启用临时常驻。窗口、采样、进程、端口均归本次会话；关闭后不保留编辑器模型。捕获辅助窗口独占租用临时Session，禁用HTTP缓存，所属窗口和任务结束后撤销权限闭包、清空临时站点数据并归还，串行开关不再创建无限增长的分区。编辑正文切换到控制条前先卸载React树；退出时等待最后一个必要任务结束后再卸载，释放视频、画布和GPU上下文。Windows uiohook 只订阅宿主已有采集，不停止或重复启动全局监听。原生组件源代码位于 `electron/native/`，运行文件位于仓库 `resources/presentation/native/bin/win32-x64/`，保留上游 helpers-manifest.json。当前正式支持范围是 Windows x64。

普通指令通过隐藏准备的独立宿主直达控制条，不先展示项目页或编辑页。点击控制条“选择录制来源”在按钮上方展开紧凑菜单，按屏幕和应用窗口分组显示单列缩略图；再次点击、Esc、取消或失焦收起，保留此前来源。来源菜单复用当前控制条，不创建额外原生窗口；选择后收起菜单，前置目标窗口并显示中心透明的绿色流动边缘，动画结束即释放。来源身份与实际捕获继续使用原版 Electron 捕获列表及原生窗口边界；Windows 窗口枚举、前置与跟踪共用本轮操作链的隐藏查询进程，空闲两秒及会话退出回收，跟踪不并发堆积。控制条与备用来源窗口设置演示录屏原生图标及独立任务栏身份；六点手柄、简洁麦克风与撤销重做箭头为本轮原创 SVG。编辑正文按视口伸缩，首次窗口适配当前工作区并预留时间轴，空轨道加号调用统一视频/项目导入。

手动和自动新增缩放均默认1.5×，已有项目内的倍率保持不变。在变焦轨道空白处悬停可预览落点区间，点击直接添加；默认最长两秒，临近下一缩放或录屏结尾时自动缩短，不覆盖已有缩放。工具栏保留自动识别，不再提供手动添加缩放按钮。自动识别同时考虑点击、移动后的小范围停留及连续移动的焦点，默认片段约两秒；跨区域操作分段，连续移动每四秒最多补一个候选，静止和细小抖动不强制放大。裁剪、变速及重复素材先将源轨迹映射到剪辑时间轴；候选与已有缩放局部重叠时保留包含操作的可用部分，已有片段不覆盖。新录制的自动应用开关不再阻止用户主动点击“自动添加变焦”。

摄像头侧栏只调整成片中的画中画，录制设备在控制条选择。尺寸按成片较短边计算，画面高度随素材裁剪比例自动匹配；位置直接在预览窗口拖放，使用与导出共用的归一化坐标，越界拖动限制在边距内，取消拖动恢复原位置。人像画面圆角缺省100%，与坐标、边距、裁剪、阴影和镜像集中在高级区域；普通设置提供显示、整体比例缩放、宽高及比例锁定和素材导入。独立宽高与整体缩放采用同一项目尺寸，手动尺寸不会被旧自动裁剪匹配覆盖。“屏幕放大时缩小人像”明确解释缩放反向联动。

系统音频和麦克风伴随素材首次加载即为独立可编辑音轨；名称固定在左侧轨道栏，点击任一音轨打开音频检查器。场景提供独立的背景圆角与录屏视频圆角，预览、项目与各导出链共用；MP4的外沿透明角在编码后显示为黑色。裁剪弹窗使用紧凑布局，支持八向手柄、移动选区、重新框选、自由/原始/常用比例及取消恢复，暂停时不持续刷新裁剪画布。

新资料空间默认将演示录屏追加到超级面板的第六个固定位置；已保存的固定列表、空列表和自定义顺序均保留。

Windows画面、摄像头、系统声音和选定麦克风分别通过WGC、MediaFrameReader和WASAPI原生采集，并与编码器并行准备，取得真实画面后才提交共同起点；倒计时期间不写入正式素材。开始、暂停、恢复和停止共享精确时间边界，原生画面按WGC时间戳、系统声音按WASAPI样本时间切片，相机按SystemRelativeTime/QPC时间戳过滤准备和暂停区间；两路视频按同一60Hz输出时间轴编码，30Hz等低帧率相机保留其实际采样节奏。启动不再等待PowerShell显示器枚举或固定窗口激活延时；窗口使用WGC真实窗口捕获，屏幕和区域继续按显示器捕获。两路声音保留独立素材，尾部按共同视频时长发布，不再用容器长度差反推内容偏移。停止后等待全部素材发布再进入编辑器；重复录制通知不清空轨迹或重置时钟。预览通过已提交视频帧的媒体时间同步光标和相机，不以 React 回写状态代替帧时钟。预览和导出共用以帧时间为中心的光标滤波，点击处经过真实坐标，任意跳转和掉帧不积累位置延迟。稀疏点击及形状索引按轨迹弱引用缓存，释放素材后可回收；视频纹理和叠加层一同提交，暂停时避免重复 GPU 重绘，界面播放进度最多每秒更新30次。摄像头关闭使用摄像头轮廓加斜线。编辑器标题、设置正文、工具提示和无障碍名称统一中文，未提供内容的高级分类不显示。原生程序本轮从仓库源码重新编译，见[构建说明](electron/native/wgc-capture/README.md)。

项目主页“设置”保留通用、录制和文件分类；通用提供“自动为新录制应用变焦”，不重复快捷键入口。选中缩放片段后可调整默认开启的“连接变焦”和“运动效果”；运动效果在普通选项中提供平滑、专注二选一，缺省平滑，不再显示经典动画开关或运动预设。它只更新缩放时长，保留光标单独设置，并沿现有项目与偏好保存链立即应用到预览和后续导出。各侧栏高级选项通过普通选项后的“高级”标题展开，当前分类重置统一位于右上角；重置人像不删除素材。旧默认运动偏好首次升级为平滑，已有项目仍按项目参数恢复。权限在实际开启设备时请求；已有项目恢复其已保存参数。来源和完整许可告知集中在 TabDo“设置 → 关于”，项目侧栏不重复显示致谢。

生成桥接：`node scripts/build-presentation.cjs`。工具构建与 E2E 自动执行此步骤，不打包 Electron 应用。源码入口使用同一 `15178` 工具服务器的 `presentation.html`；正式程序由内置工具目录提供本地页面。编辑器隐藏或最小化时保留当前独立会话，关闭时释放所属资源。

演示录屏始终录制鼠标；按需开启“录制按键”、系统音频、麦克风和摄像头。停止后按键自动载入轨道，在“按键”侧栏通过“显示按键输入”开关控制显示，并在下方调整外观；关闭显示保留已编辑内容，右上角“重置”恢复默认外观和显示。系统音频、麦克风和摄像头素材自动进入独立轨道，名称固定在左侧；点击声音调整音量、响度及淡入淡出滑条，素材起点随片段裁切和分割自动确定；摄像头画中画仍在侧栏设置。选中片段后，剪刀在游标处只分割该片段；切口紧邻且无竖条。右键片段可分割、删除，声音可静音或恢复音量，录屏可复制。拖动片段可调整同轨顺序，拖动左侧轨道名称可调整整轨排列，顺序随项目保存。拖动时显示落点提示，名称旁不显示手柄。缩放与横向浏览及时更新视频帧图，录屏和摄像头选区显示明显轮廓；点击固定刻度或片段外留白可定位游标。音频悬停显示名称、起止时间和时长。底部比例滑杆与加减按钮调整展示尺度，“适应全部”恢复全览；滚轮上下浏览，Shift＋滚轮或横向滚动条左右浏览，Ctrl＋滚轮调整比例。编辑片段时保留已选比例，刻度与显示到毫秒的游标时间在纵向滚动时固定。注释的模糊和马赛克相邻，只有聚焦、模糊、图片和马赛克提供圆角调节。

鼠标始终录制，按键默认关闭，按键选择仅保留在当前控制条会话；停止即移除采集监听，关闭会话恢复默认；记录物理按键与快捷键，不读取输入法提交文本。按键轨道在成片中叠加，原录制素材不被改写。

原始录制页的删除会将选中的库内素材及其专属伴随文件移入系统回收站，外部导入原文件不变；旧版本仅隐藏但仍在磁盘上的素材重新列出，可按新行为删除。项目删除前停止当前项目的待保存写入并卸载素材，防止自动保存重新生成项目。摄像头以补齐时长的WebM独立保存，不替换当前录屏、项目或光标轨迹；Windows屏幕和应用窗口统一使用WGC原生捕获，并明确禁止将系统指针写入画面，摄像头、屏幕及两路音频在同一操作边界启动、暂停、恢复和停止。

项目主页“设置 → 文件”可更改项目保存目录，用于随后新建的项目；已有项目仍在原位置自动保存，目录切换不搬动素材或覆盖设备偏好。预览保留系统编辑指针，与作品中的录制光标独立；音量旁可切换全屏，普通和全屏预览均提供播放、暂停、进度定位和退出操作。纯按键事件不参与光标位置和自动缩放推断。

Windows 原始素材删除使用不请求提权的系统回收接口，只处理本次选中的录制包；不可回收或权限/占用失败时恢复原件并显示原因，不退化为永久删除。列表查询不再自动回收遗留暂存目录。

Windows回收引擎返回源安全访问拒绝（0x80270021）时，先复制本次素材包到当前用户临时目录，以新文件权限完成系统回收，成功后才移除原暂存包；失败清理新副本并恢复原件，不更改用户目录权限。Windows无指针捕获不可用时明确失败，不静默退回可能录入系统指针的浏览器链。旧视频中已经写入的系统指针无法由预览开关消除，需要重新录制。

项目页支持多选后“加入文件夹”，追加成员且保留已有归类；单个项目菜单不再提供分享。原始录制删除前列出仍引用它的项目，确认后先保存并卸载当前关联媒体，再回收素材。缺失素材的项目保留编辑记录并显示“素材缺失”，打开时提供恢复说明与独立删除入口，提示不带入设置页；项目文件、缩略图和备份作为一个事务回收，失败恢复原件，不检查或删除所引用的素材。

编辑历史覆盖轨道排列、录屏/声音/注释/按键/字幕、摄像头及外观参数。切换选区不占撤销步数、不清空重做；指针拖动合并为一次编辑，撤销后进行新编辑会清空旧重做分支。历史只属于当前项目会话，不把资料库的文件回收当成编辑撤销。箭头方向通过预览旋转或侧栏角度调整；直线、饱满、双向、虚线、弧形和缎带共六款卡通 SVG 外观，默认小号白底黑边，预览和导出共用描边与阴影。光标保留原有六种外观，移除上轮新增四款并兼容回退。单选卡片在明暗主题下显示明确的主题色内轮廓。

按键以独立实体键帽绘制，空格、回车、删除和方向键提供键盘图例。侧栏以统一键帽大小同步缩放文字与显示框，颜色编辑复用注释菜单；按键分组最大间隔按相邻按下时间差计时，小于或等于阈值时同组显示；连接只影响呈现，保留原始事件与片段。同轨当前只呈现最新输入及其连接组，尾边界不重复覆盖。模糊、马赛克和聚焦支持矩形、圆形/椭圆与手绘笔画；每笔支持取消、撤销和重做。普通及全屏预览在音量旁提供全屏切换，底部进度条可按编辑时间轴定位。所有注释与按键默认无动画，选择效果后才显示时长，按媒体时间计算，暂停定位与导出一致。操作与兼容边界见[预览、按键与注释](../../../docs/presentation-visual-effects.md)。

新录制与新导入使用出厂外观，已有项目恢复各自保存的参数。分类重置不再读取上次编辑偏好；场景保留裁剪，摄像头保留素材、源时长和剪辑，音频恢复100%音量、关闭归一化及淡入淡出。具体值见[编辑默认值与重置](../../../docs/presentation-editor-defaults.md)。轨道名称使用所属指针会话排序，重新进入项目后仍可拖动，取消、失焦和完成均清理落点。

摄像头菜单中的“悬浮预览已开启/已关闭”反映当前悬浮预览开关。关闭态在指针移开后仍有底色。支持能力确认成功后，开启会显示可拖动和调整尺寸的实时预览，关闭菜单不关闭预览。预览全片终点与屏幕共同保留最后一帧相机，不延长独立相机片段或修改录制文件；内部切口及较短相机素材仍按自己的结束边界隐藏。

连续WASAPI音频包以可靠首包QPC与设备帧计数关联，避免逐包时间戳抖动造成静音插入或采样裁切；真实缺口与设备重置重新校准。长时录制的不同硬件时钟漂移仍须设备验收。
