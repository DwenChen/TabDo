# 演示录屏与演示编辑器

基于 [Recordly](https://github.com/webadderallorg/Recordly/tree/109ca3a13c362e969d9add25d1f93406c36dba2a)，固定提交 `109ca3a13c362e969d9add25d1f93406c36dba2a`，上游 package 版本 1.4.0。研究与修改日期：2026-10-27。原作者 webadderall；源自 Siddharth Vaddem 的 OpenScreen。完整许可见 [LICENSE.md](LICENSE.md)，依赖许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

本目录保留上游编辑器、录制与项目格式的来源；`tabdo-*` 文件及宿主服务负责适配。没有执行上游 main、更新器、独立托盘或账户服务。中文为唯一语言；主题由 TabDo 注入，六项编辑动作在设置的快捷键页管理，初始关闭。原有“录屏”功能及其配置保持独立。

工具入口为 `presentation-recorder`，直接显示浮动录制控制条；通过控制条的“演示编辑器”进入编辑页，项目、最近项目和导入入口集中在该页。编辑页“开始录制”返回控制条，停止后进入编辑。单个 `.recordly` 文件匹配 `presentation-editor`。项目文件保持上游格式，引用视频、声音等原始素材；转移项目时也要保留引用的素材。所有项目（含未命名项目）及编辑改动自动保存，工具栏提供撤销、恢复、“导入项目”和导出。循环光标使末尾的光标动画回到起点，便于循环观看，不移动系统鼠标。

宿主先把视图分离，再按 WebContents 创建独立模块闭包和带前缀的 IPC；控制条获取焦点不再触发主搜索窗口的失焦清理。控制条可见时隐藏编辑宿主并卸载编辑正文，全部所属窗口退出前台后按普通生命周期回收，不自动启用临时常驻。窗口、采样、进程、端口均归本次会话；关闭后不保留编辑器模型。Windows uiohook 只订阅宿主已有采集，不停止或重复启动全局监听。原生组件源代码位于 `electron/native/`，运行文件位于仓库 `resources/presentation/native/bin/win32-x64/`，保留上游 helpers-manifest.json。当前正式支持范围是 Windows x64。

普通指令通过隐藏准备的独立宿主直达控制条，不先展示项目页或编辑页。点击控制条“选择屏幕”在按钮上方展开紧凑菜单，按屏幕和应用窗口分组显示单列缩略图；再次点击、Esc、取消或失焦收起，保留此前来源。来源菜单复用当前控制条，不创建额外原生窗口；选择后收起菜单，前置目标窗口并显示中心透明的绿色流动边缘，动画结束即释放。来源身份与实际捕获继续使用原版 Electron 捕获列表及原生窗口边界；Windows 窗口枚举、前置与跟踪共用本轮操作链的隐藏查询进程，空闲两秒及会话退出回收，跟踪不并发堆积。控制条与备用来源窗口设置演示录屏原生图标及独立任务栏身份；六点手柄、简洁麦克风与撤销恢复箭头为本轮原创 SVG。编辑正文按视口伸缩，首次窗口适配当前工作区并预留时间轴，空轨道加号调用统一视频/项目导入。

手动和自动新增缩放均默认1.5×，已有项目内的倍率保持不变。自动识别同时考虑点击、移动后的小范围停留及连续移动的焦点，默认片段约两秒；跨区域操作分段，连续移动每四秒最多补一个候选，静止和细小抖动不强制放大。裁剪、变速及重复素材先将源轨迹映射到剪辑时间轴；候选与已有缩放局部重叠时保留包含操作的可用部分，已有片段不覆盖。新录制的自动应用开关不再阻止用户主动点击“自动添加缩放”。

摄像头侧栏只调整成片中的画中画，录制设备在控制条选择。尺寸按成片较短边计算，画面高度随素材裁剪比例自动匹配；位置使用中文九宫格，尺寸、边距、坐标、圆角、阴影和镜像均提供就地说明。“屏幕放大时缩小人像”明确解释缩放反向联动。

新资料空间默认将演示录屏追加到超级面板的第六个固定位置；已保存的固定列表、空列表和自定义顺序均保留。

Windows 原生捕获就绪后立即采集轨迹，重复录制状态通知不清空轨迹或重置时钟；暂停和恢复共用视频的操作边界，浏览器捕获传入实际启动时间。预览通过已提交视频帧的媒体时间同步光标和相机，不以 React 回写状态代替帧时钟。预览和导出共用以帧时间为中心的光标滤波，点击处经过真实坐标，任意跳转和掉帧不积累位置延迟。稀疏点击及形状索引按轨迹弱引用缓存，释放素材后可回收；视频纹理和叠加层一同提交，暂停时避免重复 GPU 重绘，界面播放进度最多每秒更新30次。摄像头关闭使用摄像头轮廓加斜线。编辑器标题、设置正文、工具提示和无障碍名称统一中文，未提供内容的高级分类不显示。

偏好统一放在项目主页“设置”，编辑工具侧栏不重复提供设置齿轮，权限在实际开启设备时请求。运动预设立即应用到当前项目的预览与后续导出，并保存为新项目的偏好；重新打开已有项目时恢复项目内保存的效果参数。来源和完整许可告知集中在 TabDo“设置 → 关于”，项目侧栏不重复显示致谢。

生成桥接：`node scripts/build-presentation.cjs`。工具构建与 E2E 自动执行此步骤，不打包 Electron 应用。源码入口使用同一 `15178` 工具服务器的 `presentation.html`；正式程序由内置工具目录提供本地页面。仅用户开启标题栏临时常驻后保留隐藏或最小化的独立会话，默认不落库。
